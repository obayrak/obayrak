▶ FIT MODULE — HOW IT WORKS
Levenberg-Marquardt Algorithm
Minimizes χ² = Σ [(yᵢ - f(xᵢ,p)) / σᵢ]² using adaptive damping between gradient descent and Gauss-Newton steps.
PARAMETER SETUP
Initial valueStarting point for optimizer — critical for convergence
Min / Max boundsLeave blank for unbounded; use to enforce τ>0, A>0 etc.
Y Error columnEnables weighted fit: wᵢ = 1/σᵢ². Without it, all points equal weight
Max iterations2000 default; increase for slow-converging models
Convergence tol1e-10 default; relax to 1e-7 if oscillating
GOODNESS-OF-FIT INDICATORS
χ²/ν ≈ 1Good fit — model matches data within errors
χ²/ν < 0.5Overfitted or error bars too large
χ²/ν > 5Poor model or underestimated errors
R² → 1High explained variance (use with χ²/ν together)
p-value > 0.05Fit is statistically acceptable
Rel error < 20%Parameter is well-constrained
Rel error > 50%Parameter poorly determined — simplify model
AUTO FIT
Tries all ~38 models automatically with smart initial guesses. Ranks by AIC (Akaike Information Criterion). Click any row in the ranking table to apply that model. Best model is applied automatically.
▶ MODEL COMPARISON — AIC / BIC
Run multiple fits → click Save → Compare after each. Then go to the Compare tab.
AICχ² + 2k — penalizes extra parameters lightly
BICχ² + k·ln(N) — penalizes extra parameters more heavily for large N
ΔAIC < 2Strong support — model is competitive
ΔAIC 2–4Considerable support
ΔAIC > 10Essentially no support
Akaike weightRelative probability that model is best
F-testTests whether complex model is significantly better than simpler nested one

▶ TIPS & COMMON ISSUES
Fit not converging? Use Auto Fit first, then use its best params as starting point for manual refinement
χ²/ν ≫ 1? Model is wrong, or error bars are underestimated — try a different model or add background term
χ²/ν ≪ 1? Error bars are too large, or model has too many parameters — simplify
Fit curve not on plot? Run fit first, then check "Show fit curve" in Plot 2D overlays, click Update
Theory f(x) not showing? Check "Theory curve" checkbox and click Update Plot
Log scale with negatives? Remove negative/zero values in Process → Outlier or column arithmetic
Large relative errors? Parameter is unconstrained — set bounds or fix it to a known value via Custom model
AI not responding? Paste your Anthropic API key (sk-ant-...) in the AI tab key field
