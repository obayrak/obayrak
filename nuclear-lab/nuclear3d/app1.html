Radial Schrödinger Equation

For a particle with orbital angular momentum ℓ in a central potential, the radial wave function u(r) = r·R(r) satisfies:

−ℏ²/(2μ) · d²u/dr² + Veff(r)·u(r) = E·u(r)

Rearranged as a standard second-order ODE:

d²u/dr² = −k²(r)·u(r)
k²(r) = (2μ/ℏ²)·[E − Veff(r)]

Bound states: E < 0, u(r→∞) = 0. The nr-th state has nr radial nodes.

Effective Potential — Unified Selection

All contributions to Veff are treated on equal footing. The user adds each term individually from the accordion:

Veff(r) = Σi Vi(r)   (sum of selected)
  • VL — centrifugal barrier
  • VC, VSC — Coulomb (point/core)
  • VWS, VWS², VWSS — Woods-Saxon family
  • Vcosh — Pöschl-Teller
  • VG, VY — Gaussian / Yukawa (origin-based)
  • Vexp — Shifted Exponential
  • VY-R — Shifted Yukawa (surface)
  • VG-R — Shifted Gaussian (surface)
  • VSO — WS Thomas spin-orbit
  • SO-WS², SO-G, SO-Y, SO-E — derivative SO forms
Woods-Saxon Potentials

Common geometry definitions used throughout the WS family:

CC = AP1/3 + AT1/3
R = rv · CC
x = (r − R) / a
VWS(r) = −V₀ / [1 + exp(x)]
VWS²(r) = −V₀ / [1 + exp(x)]²
VWSS(r) = −4Vs · exp(x) / [1 + exp(x)]²
  • V₀ ≈ 50–70 MeV; rv ≈ 0.9–1.1 fm; a ≈ 0.5–0.7 fm
  • WS² has sharper surface falloff (~exp(−2x)) — needs larger V₀
  • WSS peaks at r = R with value −Vs; models surface absorption
  • As r → 0: WS → −V₀/(1+exp(−R/a)); WS² squares that denominator
Coulomb Potentials (Point & Spherical Core)

Coulomb term use a uniform-sphere model inside Rc and a point-charge form outside:

VC(r ≤ Rc) = K·Zeff/(2Rc)·[3 − (r/Rc)²]
VC(r > Rc) = K·Zeff/r
  • K = e²/(4πε₀) = 1.43997 MeV·fm
  • Rc = rc · CC = rc·(AP1/3+AT1/3)
Shifted Analytic Potentials

These forms are centred at the nuclear surface R rather than the origin:

CC = AP1/3 + AT1/3
R = r₀ · CC
Vexp(r) = −V₀ · exp[−(r−R)/a]

VY-R(r) = −V₀ · exp[−(r−R)/a] / r

VG-R(r) = −V₀ · exp[−((r−R)/a)²]
  • Vexp: decays exponentially outward from R; peaked at surface
  • VY-R: shifted Yukawa; extra 1/r falloff; use ℓ ≥ 0 (finite at R)
  • VG-R: Gaussian envelope centred at R; symmetric about surface
  • All three reduce to the standard origin forms when R → 0
Origin-Centred Analytic Forms
VG(r) = −V₀·exp[−(r/Rg)²]
VY(r) = −V₀·(Ry/r)·exp(−r/Ry)
Vcosh(r) = −V₀/cosh²(r/a)
  • Gaussian VG: Fourier transform also Gaussian; used in M3Y; Rg=r₀·CC
  • Yukawa VY: meson-exchange (OPEP); diverges at origin — use ℓ>0; Ry=r₀·CC
  • Cosh: Pöschl-Teller; exactly solvable in 1D; symmetric, peaked at r=0
Spin-Orbit — Thomas Form

The standard WS spin-orbit term uses the Thomas reduction of (1/r)(dV/dr):

x′ = (r − Rso) / aso
Rso = rso · CC

VSO(r) = −λπ⟨ℓ·s⟩·Vso· e−x′ / [(1+e−x′)²·aso·r]

⟨ℓ·s⟩ = [j(j+1)−ℓ(ℓ+1)−s(s+1)] / 2
  • x′ is the reduced radial coordinate shifted to Rso: x′ = (r−Rso)/aso
  • The Thomas kernel e−x′/(1+e−x′)² is the derivative of the WS form factor
  • j=ℓ+½: ⟨ℓ·s⟩=+ℓ/2 (lowers energy); j=ℓ−½: ⟨ℓ·s⟩=−(ℓ+1)/2
  • λπ≈2 fm²; K = 1.43997 MeV·fm
Spin-Orbit Derivative Forms

Thomas spin-orbit terms derived from the shifted analytic potentials. Let:

R = P2 · CC,  E = exp[−(r−R)/P3]
RH = (r−R)/P3
C = λπ⟨ℓ·s⟩
SO-WS²: −C·P1·E²/(1+E)³ / (2r·P3)
SO-Gauss: −C·P1·exp(−RH²)·RH / (2r·P3)
SO-Yukawa: −C·P1·E·(1+r/P3) / (4r³·P3)
SO-Exp: −C·P1·E / (4r·P3)
  • Each form is proportional to (1/r)·dV/dr of the corresponding central potential
  • P1 = strength (MeV); P2 = radius parameter (fm); P3 = range/diffuseness (fm)
  • All vanish when ℓ = 0 (C = 0 since ⟨0·s⟩ = 0)

Load a preset using the Quick Presets buttons — each preset activates the correct set of potentials automatically.
