    1 · The Igo ambiguity

    Elastic scattering of strongly absorbed projectiles (α, heavy ions) probes the nuclear potential only near the strong-absorption radius Rs; the interior is hidden by absorption. Any real potential with the same value (and similar slope) there gives nearly the same cross section. For a Woods–Saxon form f = [1 + e(r−R)/a]−1 the tail is V0e−(r−R)/a, so

    V0 eR/a = const  ⇔  ΔV0/V0 = −ΔR/a   (continuous Igo ambiguity, G. Igo 1959)

    On top of that line there is a discrete ambiguity: deeper potentials that hold one more node in each partial wave give again the same scattering (the phase shifts change by π). These are the families; in a cluster picture each family corresponds to a different number of radial nodes n of the bound α + core states, labelled by

    G = 2n + L   (global quantum number of the band)

    The well-determined combinations are the volume integral and the potential at the surface:

    JV/(ApAt) = 4π/(ApAt) ∫ V(r) r² dr,    ⟨r²⟩½ = [∫V r⁴ dr / ∫V r² dr]½,    V(Rs)

    Idea of the workbench: bound and quasi-bound states depend on the whole potential (depth and node count), widths on the barrier, B(E2) on the size of the wave function, and scattering on the surface. Each class fixes a different direction in parameter space; together they can select one family and one geometry.

    2 · Two-body model

    The α particle (or any cluster Ap, Zp) moves relative to an inert core (At, Zt). For each partial wave L the radial function uL(r) obeys

    u″ = [ L(L+1)/r² + K (VC(r) + UN(r, E, L) − E) ] u,    K = 2μ/ħ²
    • Masses from atomic mass excesses (AME2020) minus electron masses; μ = mpmt/(mp + mt); ħc = 197.3269804 MeV fm, e² = 1.43996448 MeV fm, u = 931.49410242 MeV.
    • Energies are centre-of-mass energies relative to the threshold: E = Ex − Sα for compound-nucleus levels, with Sα from AME2020.
    • Coulomb: uniformly charged sphere of radius RC = rC·(Ap⅓ + At⅓): VC = ZpZte²(3 − r²/RC²)/(2RC) inside, ZpZte²/r outside.
    • Radius convention (side panel): R = r·(Ap⅓ + At⅓) (default, FRESCO "sum") or R = r·At⅓. The same r means different R in the two conventions; never compare r values across them.

    The nuclear potential is

    UN(r, E, L) = −V(E, L) f(r) − ΔV(r, E) − i W(r, E, L)

    with the real depth V(E, L) = V0(1 − βE)[1 − cM·odd(L)]·λ(L) (λ is the optional L-dependent extension, section 4) and the imaginary part acting only in scattering. Bound and quasi-bound states are eigenstates of the real potential.

    Folding. UF(r) = ∫∫ ρp(r1) ρt(r2) v(|r + r2 − r1|) d³r1d³r2, evaluated in momentum space:

    UF(r) = (1/2π²) ∫ ρ̃p(q) ρ̃t(q) ṽ(q) j0(qr) q² dq,   ρ̃(q) = 4π∫ρ(r) j0(qr) r² dr

    M3Y effective interaction (direct Yukawas + zero-range exchange at E = 0): Reid v(s) = 7999 e−4s/(4s) − 2134 e−2.5s/(2.5s) MeV, J00 = −276 MeV fm³; Paris 11062, −2538 MeV, J00 = −590 MeV fm³. A Yukawa e−μs/(μs) transforms to 4π/[μ(μ² + q²)]. Densities: Gaussian (rms), two-parameter Fermi (c, a) or harmonic oscillator (b, α), each normalised to A. The volume integral is exact: JF = ApAt·∫v d³s (e.g. −421.7 MeV fm³ per nucleon pair for Reid) — the code reproduces it, which checks the numerics. Where UF/UF(0) falls below 10⁻³ the table is joined to an exponential tail A e−(r−Rt)/α; exterior complex scaling starts there (a purely tabulated potential made the bound-state matching ill-conditioned).

    Pinpoint. The folding inputs shipped with the page are rough systematics (α: Gaussian, rms 1.46 fm; targets: 2pF with c = 1.07A⅓ fm, a = 0.54 fm). They make the shape run, not the physics right: give cited densities before drawing conclusions from the folding results.

    Changing the shape keeps JV: V0 is rescaled so that the new shape has the same volume integral, i.e. it stays in the same family.

    4 · Energy and L dependence of the real part

    Linear: V(E) = V0(1 − βE). V0 is the depth at threshold (E = 0). β links the bound states (E ≈ −5…+10 MeV) to scattering (E ≈ 20–50 MeV).

    Dispersive (side panel "Real energy dependence"): causality connects the real and imaginary parts (Mahaux, Ngô, Satchler). With W(E′) = 0 below the onset EW and the subtraction at E = 0 (so V0 keeps its meaning),

    ΔV(r, E) = (1/π) [ P∫ W(r, E′)/(E′ − E) dE′ − P∫ W(r, E′)/E′ dE′ ]

    computed separately for the volume and surface absorption, with the same radial forms; ΔV > 0 is attractive. The principal value is evaluated by subtraction, P∫f(E′)/(E′ − E) = ∫[f(E′) − f(E)]/(E′ − E) + f(E) ln|(b − E)/(a − E)|, with Gauss–Legendre panels up to EW + 6 GeV (checked against a 6·10⁶-point Simpson rule to 10⁻⁵). β is then fixed at 0. It typically gives an attractive bump of a few MeV where W rises ("threshold anomaly").

    Parity (Majorana) term: V → V(1 − cM) for odd L. Splits positive- and negative-parity bands; used in the next-band test.

    Band-termination extension (off by default): λ(L) = 1 − cL[L(L+1)/Lc(Lc+1)]pL. A local L-independent potential places a band on one smooth rule; near the end of an α-cluster band (L → G) the real states lie higher (Pauli blocking of the clusters: band termination). With pL large the correction acts only at the band end. Modes: band states only (scattering unchanged), or all partial waves with L(L+1) capped at Lc(Lc+1). The report lists how much each state moves: large shifts only at the top = band termination; large shifts everywhere = the extension is compensating a wrong potential.

    5 · Absorption (scattering only)

    W(r, E, l) = [ Wv(E) fWS(r; RW, aW) + Ws(E) · 4ex/(1 + ex)² ] · w(l),   x = (r − RD)/aD
    • Geometry: volume (WS), surface (derivative WS, peak value WD at RD) or both. Surface absorption is typical for α on heavy targets.
    • Energy dependence W(E): constant; threshold W(E) = W·(E − EW)²/[(E − EW)² + ΔW²] above EW (multiplies both terms); linear W + sWE (volume term, or WD when surface only).
    • l dependence w(l): Chatwin form w = [1 + e(l − kRl)/Δl]−1 — partial waves with impact parameter beyond Rl are weakly absorbed, which lets the anomalous large-angle (ALAS) rise through; parity form w = 1 + cWπ(−1)l; or both. Writing the cut-off as kRl makes it scale with energy.

    Well-determined absorption quantities, reported after every fit: JW/(ApAt) and W(Rsa), the absorption at the strong-absorption radius. Near or below the barrier only W(Rsa) is fixed; depths and volume-vs-surface cannot be told apart (seen for α + ²⁰⁸Pb at 23–27 MeV).

    6 · Bound and quasi-bound states (Project Gamow engine)

    Wildermuth condition. The relative motion must carry at least the oscillator quanta that the four nucleons of the α particle would have in the lowest free shells of the compound nucleus: G = Σi=1..4 Ni (8 for ²⁰Ne, 12 for ⁴⁴Ti, 22 for ²¹²Po). States with 2n + L < G are Pauli forbidden; the physical band has 2n + L = G, so n = (G − L)/2.

    Bound states (E < 0): Numerov integration (step hin = 0.005 fm by default) with Sturm-sequence node counting, so that the state with exactly n nodes is found by bisection.

    Quasi-bound (Gamow) states (E > 0): outgoing-wave poles E = Er − iΓ/2 of the S-matrix. Exterior complex scaling r = Rm + s eiθ beyond Rm (θ = 0.9; 0.7 with Gaussian terms) turns the outgoing wave into a decaying one; the pole is found with a complex secant on the matching Wronskian. The state is labelled by depth continuation: start from a deeper potential where the (L, n) state is bound and follow it as the depth is reduced to the physical value. Narrow states (Γ < 10⁻⁶ MeV) use the flux formula Γ = 2k|u(R)|²/(K∫|u|²) outside the barrier.

    Energy-dependent depth (β ≠ 0 or dispersive): the state energy is solved self-consistently, E = E(V(E)), with a secant iteration.

    Numerical checks (tab 8): every pole is re-solved with halved steps and with a different contour angle and 1.5× longer contour (a true pole does not move); pole and flux widths are compared; scattering is recomputed with half the step.

    7 · Widths, preformation and reduced widths

    Γα(exp) = Γtot × bα,   Γtot = ħ ln2 / T½ (or the listed width);   Γα(model) = Pα Γsp

    Γsp is the single-particle (pure cluster) width of the (L, n) Gamow state. The preformation factor Pα (lgPa = log₁₀Pα) absorbs the cluster probability; it cancels in width ratios ΓL/ΓL′. With a single absolute width Pα is degenerate with the geometry — its error then tells you the width carries no information on the potential.

    Reduced width θ² = Γα(exp)/Γsp(Eexp), with Γsp computed after tuning the depth so the state sits at the measured energy. θ² ≈ 0.1–1 marks an α-cluster state; θ² ≪ 0.05 a state of different structure. The protocol uses θ² to pick the members of the next band.

    8 · Electromagnetic transitions

    B(EL; Li → Lf) = (2L+1)/(4π) · eL² · ⟨Li0 L0 | Lf0⟩² · | ∫ ui rL uf dr |² × fB
    eL = Zp(At/A)L + Zt(−Ap/A)L   (cluster effective charge)

    fB (fB) is one normalisation (core polarisation) for the whole chain, so the shape of the chain 2⁺→0⁺, 4⁺→2⁺, … tests how the wave functions change along the band; the ratios to B(E2; 2⁺→0⁺) do not depend on fB. Quasi-bound states are normalised with the Berggren c-product; B(E2) is then complex, and its real part is compared with data (a warning appears when Im/Re > 10 %).

    Γγ(E2) = ħλ = (8π·3)/(2·[5!!]²) · e² B(E2) · (Eγ/ħc)⁵ ≈ 8.05·10⁻¹³ B[e²fm⁴] Eγ[MeV]⁵ MeV

    1 W.u.(E2) = 0.0594 A4/3 e²fm⁴. From ENSDF: Γγ of a transition = Γtot × bγ × Iγ/Σ I(1 + αconv); a listed B(E2) without uncertainty is replaced by the one implied by the lifetime, which has one.

    9 · Elastic scattering (Firuze engine)

    Partial-wave Numerov solution matched to Coulomb functions (WKB/Langer beyond the turning point); S-matrix Sl = ηle2iδl; nuclear amplitude added to the Rutherford amplitude; observables σ/σRutherford(θcm) and

    σR = (π/k²) Σ (2l+1)(1 − |Sl|²)

    Strong-absorption radius: |Sl| = ½ interpolated in l, Rsa = [η + (η² + (l + ½)²)½]/k (Coulomb orbit). For finite differences the grid (step, matching radius, lmax) is frozen at the reference potential; otherwise the adaptive grid makes cross sections step functions of the parameters and Jacobians are noise.

    10 · Experimental data and their uncertainties

    • EXFOR (IAEA exfor_master, located with exfortables_py): point-wise uncertainties combined in quadrature; normalisation errors (COMMON, ERR-SYS) kept separate (not added point by point); lab → c.m. with the page's masses; σ/σR computed; a forward-angle check (σ/σR ≈ 1 at small angles) switches off sets whose units look wrong. Points without an uncertainty stay excluded unless you assume one (written into the source).
    • ENSDF via the IAEA LiveChart API (or the bundled snapshot of ²⁰Ne, ⁴⁴Ti, ²¹²Po, retrieved 2026-10-28). LiveChart half-life uncertainties are in units of the last digit (0.11 with 2 → 0.11 ± 0.02); branching and energy uncertainties are absolute. L and n are suggested (L = J for natural parity, n = (G − L)/2): always check them.
    • AME2020 thresholds Sα (or Qα = −S); NUBASE2020 ground-state half-lives and α branchings.
    • Every row carries its citation and retrieval route. Rows without value or σ are flagged and excluded, never filled.

    11 · Statistics and fitting

    χ² = Σi [Oi(θ) − yi]² / σi²,   σi² = σexp,i² + σth²   (σth = floor, or floor × |Oi| for relative classes)

    Model-error floors (tab 2): defaults 50 keV for state energies, 5 % for widths and B(E2), 3 % for elastic and σR. They express how well a two-body potential of a given shape can describe each observable. "Fit all" raises the floor of a class with ≥ 4 points and χ²/n > 2 by √(χ²/n) until χ²/n ≈ 1 (limits: 30 % relative, 1 MeV absolute — a class at the limit counts as not reproduced). The estimated floor is a result: it measures the inadequacy of the model for that observable.

    Levenberg–Marquardt with forward-difference Jacobian; covariance C = (JᵀWJ)−1 from a central-difference Jacobian at the minimum; propagated errors of JV, ⟨r²⟩½, V(Rsa), JW, W(Rsa) by σf² = ∇fᵀC∇f. Profile likelihoods (refit at fixed value, Δχ² = 1 ↔ 1σ) and an affine-invariant ensemble MCMC (Goodman–Weare) check the Gaussian approximation.

    Staged fit ("Fit all"): 0 family seed (bisect V0 so the lowest band state sits on its datum); 0b geometry seed (3×3 grid in rV, aV, depth re-tuned at each node, ranked by band energies with the worst state dropped + mean elastic χ² per point × number of states); 0c set aside one state if |pull| > 5 and > 3× the next worst (≥ 4 states); A real part from spectroscopy (β left to C); B absorption from scattering; C everything. Then floors are estimated, at most one more unreachable spectroscopic point (|pull| > 5) per pass is set aside and reported, and a final fit with doubled iterations gives the covariance.

    Automatic free set: V0, rV, aV always (only V0 for folding); absorption parameters with scattering data; β with ≥ 3 band members of different L or scattering energies spread by more than 30 %; log₁₀Pα with absolute widths; fB with E2 data; the shape parameters and extensions you switched on.

    Verdicts: per class, the χ² probability Q(χ², n) (Wilson–Hilferty approximation): reproduced for Q ≥ 0.05, fair for 0.001 ≤ Q < 0.05, not within errors below. Family map and comparisons: Δχ² > 9 ⇔ more than 3σ for one discrete alternative. Global fit: Δχ² between global and independent fits for the Δν removed parameters.

    Pinpoint. Class balancing (tab 7 checkbox) re-weights classes as if they had equal numbers of points. It is exploratory only: the χ² and errors are then not statistical. Prefer realistic floors.

    12 · Breaking the ambiguity: the logic

    1. Band energies (≥ 3 members of different L) fix depth and shape: the spacing E(L) depends mainly on R and a; the head fixes the depth for a given n.
    2. Elastic scattering fixes the surface (V(Rs), absorption). A wrong family can reproduce the band only with a geometry that the elastic data reject.
    3. Widths fix the barrier region (with Pα, or ratios); B(E2) chains the extent of the wave functions.
    4. Family map: one complete fit per G with common floors and data; a family is excluded when Δχ² > 9, or when even its best fit cannot produce every band state.
    5. Robustness: the same G must win for several shapes (WS², Michel, folding); JV should agree within the spread of the shapes.
    6. Prediction: the opposite-parity band G + 1 (members chosen by θ²) predicted without refitting — independent evidence.

    13 · Key findings with the bundled real data (pinpoints)

    • α + ¹⁶O / ²⁰Ne: ENSDF ground band 0⁺–6⁺ (8⁺ set aside: band termination), 6⁺ and 8⁺ α widths, E2 chain, Abele 54.1 MeV elastic. All three shapes select G = 8; JV/(ApAt) ≈ 359–366 MeV fm³; χ²/ν ≈ 1.2–1.4 with an estimated elastic floor of ≈ 27 %. The K = 0⁻ band (1⁻ 5.79, 3⁻ 7.16, 5⁻ 10.26 MeV; G = 9) is predicted to 0.86 MeV rms without refitting, 0.30 MeV with cM only. Discrete ambiguity removed for these data and shapes.
    • α + ⁴⁰Ca / ⁴⁴Ti and α + ²⁰⁸Pb / ²¹²Po: the yrast levels are not reproduced as a simple α + core band (χ²/ν ≈ 42), shapes disagree on G → not removed. For ²¹²Po the yrast states are largely shell-model (seniority) states; for ⁴⁴Ti the elastic data used are limited.
    • The 30 MeV (lab) α + ¹⁶O back angles are not reproduced by any smooth absorption tried, including the Chatwin l-cut-off (χ² improved by 104 for 2 extra parameters, but the 166° point is still 9σ off; these two sets were given an assumed 10 % σ in that test).
    • One shared geometry for ¹⁶O, ⁴⁰Ca and ²⁰⁸Pb is rejected (Δχ² ≈ 350): diffuseness ≈ 1.4 fm for light systems, ≈ 0.7 fm for ²⁰⁸Pb in the sum convention.

    14 · Limits

    • Two-body, local, L-independent potential (unless an extension is switched on); no explicit antisymmetrisation (Pauli effects only through n and the Wildermuth G); no core excitation.
    • No coupled channels: inelastic couplings (¹⁶O 3⁻, 2⁺; ⁴⁰Ca 3⁻) are absorbed into W and into the model-error floor.
    • One energy-independent geometry for the real part; energy dependence only through β or the dispersive ΔV.
    • Absorption forms are phenomenological; elastic floors of 20–30 % are a sign of model inadequacy, not of bad data.
    • Folding: rough default densities; zero-range exchange at E = 0; no density dependence (DDM3Y).
    • Numerics: very broad resonances (Γ comparable to E) are hard to label; the solver may not find a state at an extreme depth — the family map then excludes that family as "cannot produce every state", which is strong but rests on the solver.
    • Statistics: floors are estimated from the same data; Δχ² > 9 is a convention; LM can stop in local minima (each family starts from the same θ with the same seeding); the 1σ errors assume linearity — check with profiles/MCMC.
    • Data: ENSDF L, n assignments are suggestions; EXFOR normalisation errors are reported but not fitted; sets without uncertainties are excluded unless you assume one.

    15 · Suggestions

    • Use cited densities for folding (electron scattering for the charge, a matter-density model for neutrons).
    • Add per-data-set normalisation parameters constrained by the EXFOR systematic errors — this should reduce the elastic floors.
    • Give the 30 and 39 MeV α + ¹⁶O EXFOR sets their published uncertainties and fit an excitation function with W(E) and the dispersive real part.
    • Coupled-channels test of how much of the elastic misfit is channel coupling.
    • Extend the ENSDF window beyond 13.5 MeV to include the higher members (7⁻, 9⁻) of the ²⁰Ne K = 0⁻ band, and test further bands (e.g. the G = 10 positive-parity band).
    • Model comparison by evidence/AIC for the extensions (L-dependent depth, l-dependent W) instead of Δχ² only.

    Manual

    How to get from a system to a defensible answer in the fewest steps, and what every control does. Times are for a desktop browser.

    Contents1 · Fastest route (one button)2 · Step-by-step workflow3 · The side panel4 · The tabs5 · Recipes6 · Speed tips7 · Troubleshooting8 · Data formats9 · Saving and reporting

    1 · Fastest route (one button)

    1. Pick a Preset in the side panel (e.g. "α + ¹⁶O → ²⁰Ne · REAL DATA"). EXFOR elastic data and the AME2020 band head load with citations.
    2. Scroll to step 5 · Run the whole protocol automatically at the top and press Run the protocol. Leave the three shapes ticked.
    3. Wait (≈ 15–20 min for ²⁰Ne, longer for heavy targets). The list fills step by step: ENSDF levels → Fit all → family map per shape → next-band prediction → verdict.
    4. Read the verdict ("ambiguity removed" / "not removed") and the reasons. Saved fits appear in tab 9 (Compare).
    Tip. For a first look untick Michel and folding: one shape takes ≈ 5 min for ²⁰Ne.

    2 · Step-by-step workflow (recommended)

    1. Choose the system. Preset, or set Ap, Zp, At, Zt in the side panel and fill the mass excesses (tab 2 → "AME2020" fills them).
    2. Choose the model (side panel): real shape (start with WS² for light, WS for heavy targets), radius convention (keep "sum"), absorption geometry, W(E) if you have several beam energies. Leave the extensions off at first.
    3. Get the data (tab 2 · Observables, or step 1 → "Add / retrieve data"):
      • ENSDF: nuclide of the compound nucleus (e.g. 20Ne), source "IAEA LiveChart", Retrieve levels + γ. If the browser blocks the request, tick "try public CORS proxies", or choose "bundled LiveChart snapshot" (²⁰Ne, ⁴⁴Ti, ²¹²Po).
      • In the level table check the ticked band members, their L and n (n = (G − L)/2 with the G box set to the Wildermuth value). Choose "E2 as" B(E2) or partial Γγ (never both). Import ticked levels.
      • EXFOR: list the sets for the system, tick those with uncertainties, import. Sets without σ need "assumed σ" (recorded in the source).
      • NUBASE2020: ground-state α width for α emitters (e.g. ²¹²Po).
    4. Check step 1 at the top: ✓ for state energies (≥ 3 different L), widths, E2, elastic. Fix every ! it shows (wrong G, missing σ, missing source).
    5. Fit all observables (step 2). Read step 3: the headline, the class table ("rms model − data" in keV or %), the fitted potential with errors, and "what the fitter did" (open the why? links).
    6. Is the ambiguity broken? Step 4 · Map the families. A family is excluded by Δχ² > 9 (green) or because it cannot produce every state.
    7. Robustness: change the real shape (side panel; V0 is rescaled to keep JV) and map again — or let step 5 do it.
    8. Look and compare: tab 7 for plots, profiles, MCMC; Save for comparison and open tab 9; tab 1 live editor to see how each parameter moves the band and the cross section.
    9. Report: tab 8 → numerical cross-checks, JSON, methods text, HTML report.

    5 · Recipes

    A new α + core system

    1. Template preset or any preset; set A, Z of target; tab 2 → AME2020 fill; set G (Wildermuth value in the side info line).
    2. ENSDF retrieve + import the ground band; EXFOR import elastic sets with σ.
    3. Fit all → family map (one shape) → step 5 with all shapes.

    The band end does not fit

    1. Keep the automatic "set aside" (the point stays visible with its prediction).
    2. Or switch on "L-dependent depth" (band states only) and fit again; read the "model extension" note: shifts only at the top = band termination.

    Several beam energies

    1. Import all sets; W(E) → threshold; optionally "Real energy dependence" → dispersive.
    2. Fit all fits the plain model first and then switches the extensions on; compare the two χ² in the log.

    Heavy target near the barrier

    1. Absorption geometry → surface; expect W depths to be unconstrained — read W(Rsa) and JW.
    2. Add excited α-decaying levels and width ratios; one ground state cannot fix the family.

    Several systems at once

    1. For each system: load, check data, step 3 → Add this system to the global fit.
    2. Tab 10: tick shared parameters (start with rV, aV), choose "V0 free per system" first, then the A⅓ trend; Global fit. Use the same shape and radius convention for all systems.

    6 · Speed tips

    • Heavy targets are slow (many partial waves, deep states): ²¹²Po protocol ≈ 75 min, the folding family map alone ≈ 35 min. Map one shape first.
    • Iterations per stage (step 2 → options): 20 is enough; raise only when the result says "not converged".
    • Changing only the absorption does not re-solve the states (they are memoised by the real part) — use the live editor freely for W.
    • Switch off classes you do not need (tab 2 chips) while exploring; switch them back on for the final fit.
    • The family map list (step 4 box) can be narrowed, e.g. "6,8,10".
    • Leave the page visible: background tabs are throttled by the browser.
