Nuclear Shell Model

How nucleons fill discrete energy levels — and why magic numbers exist

1 · Historical Background

In 1949, Maria Goeppert Mayer and J. Hans D. Jensen independently proposed that nucleons move in a mean nuclear potential with a strong spin-orbit coupling term. This gave a quantitative explanation of the empirically observed magic numbers: nucleon numbers at which nuclear binding is exceptionally strong. Both received the Nobel Prize in Physics in 1963.

Before their work, simple harmonic-oscillator potentials predicted magic numbers at 2, 8, 20, 40, 70, 112 — but experiments showed 2, 8, 20, 28, 50, 82, 126. The discrepancy above 20 was resolved by spin-orbit splitting.

2 · The Nuclear Potential

Each nucleon moves in the mean field created by all other nucleons. The most realistic form is the Woods-Saxon potential:

V(r) = −V₀ / [1 + exp((r − R) / a)] V₀ ≈ 50 MeV (depth) R = r₀ · A^(1/3) (nuclear radius, r₀ ≈ 1.25 fm) a ≈ 0.524 fm (surface diffuseness)

It approaches −V₀ deep inside the nucleus and falls to zero outside, with a surface transition region of width ~a. Adding the centrifugal barrier ℏ²l(l+1)/(2mr²) for each orbital angular momentum l completes the single-particle Hamiltonian.

3 · Spin-Orbit Coupling — The Key Insight

The crucial addition that produces the correct magic numbers is the spin-orbit interaction:

V_LS = −κ · (1/r)(dV/dr) · (L̂ · Ŝ) κ > 0 (empirically determined)

Using J = L + S, we write L̂·Ŝ = ½[J(J+1) − L(L+1) − S(S+1)]ℏ². For a nucleon with spin s = ½, each orbital-l level splits into two sub-levels:

j = l + ½ → 〈L̂·Ŝ〉 = +½·l·ℏ² (pushed DOWN in energy) j = l − ½ → 〈L̂·Ŝ〉 = −½·(l+1)·ℏ² (pushed UP in energy) Energy splitting: ΔE = κ·(2l+1) · 〈(1/r)(dV/dr)〉

The splitting grows with l. For large l values (like the 1g, 1h, 1i orbitals), the j = l+½ sub-level drops so far that it joins the shell below — this creates the magic closures at 28, 50, 82, and 126.

6 · Ground State Spin-Parity Rules

The pairing force causes pairs of identical nucleons in the same level to couple their angular momenta to J = 0. This means only unpaired nucleons contribute to the total angular momentum.

Even-Even Nuclei (Z even, N even):
All nucleons are paired. Jπ = 0+ universally. The parity is positive because all pairs contribute +1.
Odd-A Nuclei (either Z or N odd):
The single unpaired nucleon in level nlj determines:
  • Spin: J = j
  • Parity: π = (−1)l
So Jπ = j(−1)ˡ, e.g., if j = 5/2 and l = 2 → Jπ = 5/2+
Odd-Odd Nuclei (Z odd, N odd) — Nordheim Rules:
Unpaired proton in level jp, lp and neutron in jn, ln:
  • Parity: π = (−1)(lp + ln)
  • Define Ω = +1 if j = l + ½ (stretched), −1 if j = l − ½ (anti-stretched)
  • If Ωp = Ωn (same type): J = |jp − jn| (strong Nordheim rule)
  • If Ωp ≠ Ωn (mixed): J = jp + jn (weak Nordheim rule)
Note: Odd-odd predictions are less reliable; multiple J values can occur.

8 · Limitations of the Shell Model

The independent-particle shell model works best near closed shells. Away from magic numbers, residual interactions between nucleons become important, leading to:

Collective phenomena — nuclei far from closed shells can deform and exhibit rotational or vibrational excitation spectra, described by the collective (Bohr-Mottelson) model.

Configuration mixing — the actual nuclear wave function is often a superposition of multiple shell-model configurations, requiring more sophisticated many-body methods (large-scale shell model, no-core shell model).

Island of inversion — near N = 20, nuclei like ³²Mg have inverted normal ordering due to strong neutron-proton interactions driving deformation into the ground state.
