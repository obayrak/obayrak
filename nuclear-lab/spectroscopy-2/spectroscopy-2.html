NUCLEAR SPECTROSCOPY · POTENTIAL-MODEL WORKBENCH

NNDC NuDat 3 / ENSDF · IAEA LiveChart API · cluster model α+⁸Be→¹²C ready

Quick workflow

  1. Data: Test connection → Retrieve levels (or upload ENSDF/CSV). Check provenance and validation flags.
  2. Potential Builder: load the α+⁸Be preset or build terms (WS, surface, square, Coulomb, expression, table).
  3. Bound States / Resonances: solve, check convergence, optionally refine with Siegert poles.
  4. Exp vs Theory: "Compute all", review matches (never forced), set Wildermuth G.
  5. Optimization: build fit list, choose parameters, fit (energies, widths, phase shifts, cross sections) or run MCMC.
  6. Validation & Reports: run self-tests, assistants, export manifest / report. Measured, calculated, fitted and suggested values are kept separate.

1 · NuDat / ENSDF data retrieval

Applied automatically to retrieved levels before they are loaded. Ex values within the selected tolerance are treated as duplicate reports of one level. The most complete/precise record is retained; choose a smaller tolerance if nearby physical levels must remain separate. Default tolerance: 0.1 MeV.




NuDat 3 has no documented public REST API. Its level data are ENSDF evaluations, which the IAEA-NDS serves through the documented LiveChart Data Download API (nds.iaea.org/relnsd/v1/data?fields=levels&nuclides=12c, CSV; documented as an ENSDF snapshot (April 2022), so it can lag the live NuDat 3 evaluation — the snapshot note is stored in the provenance record). The app first queries the NNDC ENSDF API (www.nndc.bnl.gov/ensdf-api, JSON: /levels?nuclide=12C&limit=10000, with /qvalues and /meta/release for provenance), then falls back to the IAEA CSV API and the NNDC adopted-levels service and, for ¹²C only, a bundled offline snapshot (always labelled as such). If the browser blocks the request (CORS / offline), download the ENSDF file or CSV and use the upload fallback below.

6 · Quasi-bound states & resonances







Resonances: δℓ(E) rising through π/2 (mod π), matched to Coulomb asymptotics Fℓ,Gℓ (asymptotic series, adaptive radius, σℓ removed). Γ=2/(dδ/dE). A WKB barrier-penetration Γ is given as an independent cross-check; box (Dirichlet) eigenstates are compared against the pole/phase results and flagged as artifacts when no resonance coincides. Siegert (Gamow) poles are found by a complex secant search on the outgoing-wave log-derivative condition, started from the phase-shift resonance; broad states (Γ comparable to Er) may not converge and are then flagged. With "use Im V" ticked (default), every solver uses the complex potential V+iW when W≠0 — bound states give exact complex energies E−iΓabs/2 (log-derivative matching of complex Numerov solutions, shown beside the first-order ⟨W⟩ estimate), and the resonance scan uses it: the phase shown is the elastic phase ½·arg S (|S|<1), so Γ from 2/(dδ/dE) is the elastic-phase width, not the total width, and strong absorption can remove the resonance from the elastic phase entirely. Elastic-phase resonance search for absorptive potentials needs a scan step comparable to Γ, otherwise very narrow states can be missed.
