1 — Gauss's Law → Electric Field E(r)

By Gauss's law, for a spherically symmetric charge distribution the field at radius r depends only on the total enclosed charge Q_enc(r):

∮ E⃗ · dA⃗ = Q_enc / ε₀ ⟹ E(r) = k · Q_enc(r) / r² [k = 1/(4πε₀)]

The solid core has uniform density ρ = q₁/(4πR₁³/3), so Q_enc grows as r³ inside it:

r < R₁ : Q_enc = q₁·(r/R₁)³ → E = k·q₁·r / R₁³ (linear) R₁≤r<R₂ : Q_enc = q₁ → E = k·q₁ / r² R₂≤r<R₃ : Q_enc = q₁+q₂ → E = k·(q₁+q₂) / r² r ≥ R₃ : Q_enc = q₁+q₂+q₃ → E = k·(q₁+q₂+q₃) / r²

2 — Electric Potential V(r)

V is defined by E = −dV/dr, with V(∞) = 0. Integrating inward from infinity:

V(r) = −∫_{∞}^{r} E(r′) dr′ = +∫_{r}^{∞} E(r′) dr′

For the solid core the result is the standard uniformly-charged-sphere potential:

r ≥ R₁ : V_core = k·q₁ / r r < R₁ : V_core = k·q₁/(2R₁) · (3 − r²/R₁²) ← continuous at R₁!

Each shell adds a constant offset inside its own radius (shell theorem):

V_shellK(r) = k·q₂ / max(r, R₂) V_shellL(r) = k·q₃ / max(r, R₃) V(r) = V_core(r) + V_shellK(r) + V_shellL(r) [total, always continuous]

3 — Energy Conservation → KE(r)

The Coulomb field is conservative. The total mechanical energy is constant:

E_total = KE(r) + PE(r) = const (at all r) PE(r) = zₚ · V(r) KE(r) = E₀ + zₚ·V(r₀) − zₚ·V(r) = E₀ + PE(r₀) − PE(r)

At r₀ (entry), KE = E₀ and PE = zₚ·V(r₀). As the particle moves inward, KE and PE exchange; their sum is exactly conserved. The simulation tracks |KE + PE − E_total| as a numerical accuracy check (shown in the HUD and conservation badge).

4 — Stopping Power: Exact Derivation for This Model

Definition: Stopping power S is the energy deposited by the particle per unit path length. For inward radial motion with depth x = r₀ − r:
S(r) ≡ −dKE/dx [energy per unit depth, always ≥ 0 when decelerating]

Differentiate KE(r) = E₀ + PE(r₀) − zₚ·V(r) with respect to r:

dKE/dr = −zₚ · dV/dr = zₚ · E(r) [since E = −dV/dr]

Apply the chain rule with x = r₀ − r → dx/dr = −1 → dr/dx = −1:

dKE/dx = dKE/dr · dr/dx = zₚ·E(r) · (−1) = −zₚ·E(r)
∴ S(r) = −dKE/dx = zₚ · E(r) ← EXACT for Coulomb field

Physical interpretation: When zₚ·E(r) > 0 (particle charge and field in same direction → repulsion opposing inward motion), S > 0 and the particle deposits energy. When zₚ·E(r) < 0 (attraction → field accelerates inward motion), S < 0 meaning the particle gains energy from the field.

5 — Range (CSDA)

R = ∫₀^{KE₀} dE/S(E) [Continuous Slowing-Down Approximation] ≈ r₀ − r_stop (numerically, where KE first reaches 0)

Classical Bethe–Bloch Formula

The original Bethe–Bloch formula describes energy loss of a heavy charged particle in a dense medium via inelastic Coulomb collisions with bound electrons:

−dE/dx = (4πz²e⁴NZ) / (m_e v²) · ln(2m_e v²/I) where: z = projectile charge number N = target atom number density Z = target atomic number m_e = electron mass v = projectile speed I = mean excitation energy of target

Key feature: The 1/v² factor means stopping power increases as the particle slows down, producing the characteristic Bragg peak just before the particle stops.

Adapting Bethe–Bloch to This Coulomb Shell Model

In our model the "medium" is a concentrated Coulomb field rather than a sea of electrons, so the true Bethe–Bloch formula does not apply directly. However, we can construct an analog that captures the same physical behaviour — rising S near the stopping point — by multiplying the exact Coulomb stopping power by a velocity correction factor:

①

Pure Coulomb (exact for this field): S_C = zₚ · E(r)

②

Bethe–Bloch power correction. v(r) = √(2·KE(r)/m), v₀ = √(2·E₀/m). Dimensionless velocity ratio β = v²/v₀² = KE/E₀:

S_BB(r) = zₚ·E(r) · [1 + α · v₀²/v(r)²] = zₚ·E(r) · [1 + α · E₀/KE(r)] = zₚ·E(r) · [1 + α / β(r)] where β(r) = KE(r)/E₀ (normalised kinetic energy)
③

Bethe–Bloch log correction (closer to true B–B, includes ln term):

S_BBlog(r) = zₚ·E(r) · [1 + α · (E₀/KE(r)) · ln(v₀/v(r))] = zₚ·E(r) · [1 + α/(2β) · ln(1/β)] where β(r) = KE(r)/E₀, v₀/v = (E₀/KE)^{1/2}

Important Caveat

In a real material, stopping power has contributions from both electronic collisions (Bethe–Bloch) and nuclear elastic scattering. Our model captures the electromagnetic analogue of the Bragg peak behaviour; the numbers are in normalised simulation units, not SI.

Reading the Simulation

  • Projectile colour — hot red = high KE, cool blue = low KE. The glow shrinks as the particle loses energy.
  • Yellow/blue arrow — net Coulomb force F = zₚ·E(r). Yellow = repulsive (decelerating), blue = attractive (accelerating).
  • KE/PE bar — bottom bar shows energy partition: red = KE, violet = PE. Their sum must stay constant (conservation badge goes green).
  • Energy chart — KE(r) inward, PE = zₚ·V(r), and their sum (amber). The sum should be flat — any deviation is numerical error.
  • Stopping power chart — green = pure Coulomb S = zₚ·E(r); lime = Bethe–Bloch modified S_BB. Positive = decelerating, negative = accelerating.
  • Bragg curve — both models vs depth x = r₀−r. The Bragg peak is the sharp maximum near the end of range.

Suggested Experiments

  • Increase α from 0 → 1 with positive charges: watch the Bragg peak sharpen and shift toward the stopping point.
  • Set q₁ < 0 with zₚ > 0: attractive field gives negative S (particle accelerates inward, gaining KE).
  • Set q₁+q₂+q₃ = 0: no far-field; particle enters freely, all interaction happens near the core.
  • Increase E₀ with fixed charges: range increases, Bragg peak shifts inward.
  • Try BB-log model (dropdown): produces a more gradual rise and sharper cutoff, closer to true Bethe–Bloch shape.
