Gamow States and the Resonance Problem

What is a Gamow State?

A Gamow state (also called a resonance eigenstate or Siegert state) is a solution of the time-independent Schrödinger equation satisfying purely outgoing-wave boundary conditions at large radius. It describes an unstable nucleus or a metastable quantum state that decays by quantum tunnelling through a centrifugal or Coulomb barrier.

Unlike bound states — which have real negative energies and are square-integrable — Gamow states carry a complex energy eigenvalue:

$$E_{\text{res}} = E_r - \frac{i\,\Gamma}{2}$$

where \(E_r > 0\) is the resonance energy (position of the cross-section peak) and \(\Gamma > 0\) is the decay width (FWHM of the Breit–Wigner resonance). The corresponding mean lifetime and half-life are

$$\tau = \frac{\hbar}{\Gamma}, \qquad t_{1/2} = \tau\ln 2 = \frac{\hbar\ln 2}{\Gamma}$$

The Radial Schrödinger Equation

For a spherically symmetric (complex) potential \(V(r)\), the full wave function factorizes as

$$\psi(\mathbf{r}) = \frac{u_L(r)}{r}\,Y_L^m(\hat{r})$$

The radial function \(u_L(r)\) satisfies the reduced radial Schrödinger equation:

$$\left[-\frac{\hbar^2}{2\mu}\frac{d^2}{dr^2} + \frac{\hbar^2 L(L+1)}{2\mu r^2} + V(r)\right]u_L(r) = E\, u_L(r)$$

Rearranging into the form integrated numerically (with \(k^2 = 2\mu E/\hbar^2\), which is complex for a Gamow state):

$$u_L''(r) = \left[\frac{L(L+1)}{r^2} + \frac{2\mu}{\hbar^2}\,V(r) - k^2\right]u_L(r)$$

Here \(\mu = m_p m_t/(m_p+m_t)\) is the reduced mass and \(\hbar c = 197.329\) MeV·fm. The wave number \(k = \sqrt{2\mu E}/\hbar c\) is complex when \(E = E_r - i\Gamma/2\).

Boundary Conditions

Regularity at the origin: Requiring that \(u_L(r)\) be finite at \(r=0\) demands \(u_L(r)\sim r^{L+1}\) as \(r\to 0\). The code starts the integration at \(r_0 = 10^{-8}\) fm with

$$u_L(r_0) = r_0^{L+1}, \qquad u_L'(r_0) = (L+1)\,r_0^L$$

Purely outgoing-wave condition at large \(r\) (Gamow boundary condition):

For a neutral projectile (\(Z_p=0\)), the asymptotic form must be the Ricatti–Hankel function of the first kind:

$$u_L(r)\;\xrightarrow{r\to\infty}\;A\,\xi_L^{(+)}(kr), \qquad \xi_L^{(+)}(\rho)=\rho\,h_L^{(1)}(\rho) \;\sim\; e^{i(\rho - L\pi/2)} \text{ for large }|\rho|$$

For a charged projectile (\(Z_p\neq 0\)), the Coulomb–Hankel function takes over:

$$u_L(r)\;\xrightarrow{r\to\infty}\;A\,H_L^+(\eta,kr), \quad H_L^+ \approx e^{i\theta_L}$$
$$\theta_L(\eta,\rho) = \rho - \eta\ln(2\rho) - \frac{L\pi}{2} + \sigma_L(\eta)$$

where the Sommerfeld parameter \(\eta = Z_p Z_t e^2 \mu/(\hbar^2 k)\) measures the strength of the Coulomb interaction relative to kinetic energy, and \(\sigma_L = \arg\Gamma(L+1+i\eta)\) are the Coulomb phase shifts.

⚠ Why the Gamow function grows at large r

Because \(\text{Im}(k) < 0\) for a decaying state, \(|e^{ikr}| = e^{-\text{Im}(k)\cdot r}\) grows exponentially as \(r\to\infty\). This is not a numerical artifact — it correctly encodes the outgoing probability current leaking through the barrier. The Gamow state is therefore not square-integrable in the usual sense.

The Matching Condition

Because the Schrödinger equation is second-order, both \(u_L\) and \(u_L'\) must be continuous at any point. Defining the logarithmic derivative (R-matrix element) at the matching radius \(R_M\):

$$R_L(E) = \frac{u_L(R_M)}{u_L'(R_M)}, \qquad R_R(E) = \frac{H_L^+(k R_M)}{k\,(H_L^+)'(k R_M)}$$

The Gamow eigenvalue equation is the condition that these two quantities agree:

$$f(E) \equiv R_L(E) - R_R(E) = 0, \qquad E \in \mathbb{C}$$

This is solved in the complex energy plane. The root \(E_{\rm res} = E_r - i\Gamma/2\) is the Gamow pole.

Node-Count Filter

In a given potential there are infinitely many Gamow poles. To identify the desired level, the code counts the number of sign changes (nodes) of \(\text{Re}[u_L(r)]\) in the interval \((r_0+0.1\,\text{fm},\; R_M)\). The matching function is penalized by a factor \(10^6\) whenever the node count differs from the target \(n_r\), preventing the secant iteration from jumping to the wrong pole.

Normalization

Since the Gamow function grows asymptotically, the true Gamow normalization requires a complex integral \(\int u_L^2\,dr\) (without absolute value). Here we use the practical truncated \(L^2\) norm over \([r_0, r_{\max}]\):

$$\mathcal{N} = \left[\int_0^{r_{\max}} |u_L(r)|^2\, dr\right]^{1/2}, \qquad \tilde{u}_L(r) = \frac{u_L(r)}{\mathcal{N}}$$

The normalization check \(\int_0^{r_{\max}}|\tilde{u}_L|^2\,dr = 1\) is computed and displayed. For the reference case (n+²⁰⁸Pb, \(L=0\), \(n_r=3\)) this is unity to 16 digits (Mathematica result).

Numerical Methods

Algorithm Overview

1Set boundary conditions at \(r_0=10^{-8}\) fm from regularity: \(u(r_0)=r_0^{L+1}\), \(u'(r_0)=(L+1)r_0^L\).
2RK4 outward integration in complex arithmetic from \(r_0\) to \(r_{\max}\) with step \(h\), evaluating \(g(r)=L(L+1)/r^2 + 2\mu V(r)/\hbar^2 - k^2\) at each step.
3Node count check: count sign changes of \(\text{Re}[u(r)]\) in \((r_0+0.1, R_M)\). Reject if \(\neq n_r\).
4Matching function \(f(E)=R_L(E)-R_R(E)\) evaluated at current complex \(E\).
5Complex secant iteration updates \(E\) until \(|f(E)|<10^{-7}\).
6Full wave function computed at \(E_{\rm res}\) and normalized by trapezoidal integration of \(|u|^2\).

1 — Fourth-Order Runge–Kutta

The ODE \(u''=g(r)u\) is written as a first-order system \(\mathbf{y}=(u,v)^\top\), \(v=u'\). Since the equation is linear, only \(g\) at three points per step is needed. The classical RK4 update:

$$\mathbf{k}_j=h\,\mathbf{F}(\text{appropriate arguments}), \qquad \mathbf{y}_{n+1}=\mathbf{y}_n+\tfrac{h}{6}(\mathbf{k}_1+2\mathbf{k}_2+2\mathbf{k}_3+\mathbf{k}_4)$$

All arithmetic uses complex double precision because both \(g(r)\) (via complex \(E\)) and the wave function are complex-valued. Global error is \(O(h^4)\).

2 — Outgoing Wave Functions

Neutral (\(Z_p=0\)): Ricatti–Hankel recurrence for complex \(\rho=kr\):

$$\xi_{-1}=e^{i\rho},\;\xi_0=-ie^{i\rho},\;\xi_{L+1}=\frac{2L+1}{\rho}\xi_L-\xi_{L-1};\quad \xi_L'=\xi_{L-1}-\frac{L}{\rho}\xi_L$$

Charged (\(Z_p\neq 0\)): Leading-order asymptotic at \(R_M\):

$$H_L^+\approx e^{i\theta_L},\quad (H_L^+)' \approx i\!\left(1-\frac{\eta}{\rho}\right)e^{i\theta_L},\quad \theta_L=\rho-\eta\ln(2\rho)-\frac{L\pi}{2}+\sigma_L$$

Coulomb phase shifts \(\sigma_L=\text{Im}[\ln\Gamma(L+1+i\eta)]\) via the Lanczos approximation.

3 — Complex Secant Root Finder

Starting from \(E_0 = E_r^{(0)}-i\Gamma_0/2\) and \(E_1=1.04E_0\):

$$E_{n+1}=E_n - f(E_n)\cdot\frac{E_n-E_{n-1}}{f(E_n)-f(E_{n-1})}$$

Convergence when \(|f(E)|<10^{-7}\). Typically 10–30 iterations.

4 — Normalization

Trapezoidal integration over stored samples \(\{r_j,u_j\}\):

$$\mathcal{N}^2=\sum_j \frac{|u_j|^2+|u_{j+1}|^2}{2}(r_{j+1}-r_j)$$

User Guide

Quick Start

1Set projectile (\(A_p, Z_p\)) and target (\(A_t, Z_t\)). The reduced mass \(\mu c^2\) updates automatically.
2Choose \(L\) (angular momentum) and \(n_r\) (number of nodes of Re[ψ] inside \(R_M\)). \(n_r=0\) gives the deepest quasi-bound state.
3Select a potential form and set its parameters. The potential curve is previewed immediately (live update).
4Provide initial energy guess: \(E_r^{(0)}\) (expected resonance position) and \(\Gamma_0/2\) (expected half-width). These define \(E_0 = E_r^{(0)}-i\Gamma_0/2\) in the complex plane.
5Click Compute Gamow State. Watch the status bar — green = converged.
6Toggle plot layers (Re/Im/|ψ|²/potentials) using the checkboxes. Set custom axis ranges and click Apply. The dashed vertical line marks \(R_M\).
