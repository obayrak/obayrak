Quantum Two-Body Scattering Simulator — Manual & Physical Basis

1 · Two-Body Problem and Reduced Mass

The relative motion of two particles with masses m₁ and m₂ interacting via a central potential V(r) reduces exactly to a one-body problem with the reduced mass:

μ = m₁·m₂ / (m₁ + m₂) Physical units used throughout: ħc = 197.3269804 MeV·fm (exact CODATA value) mₑ = 0.51099895 MeV/c² mp = 938.27209 MeV/c² mn = 939.56542 MeV/c² α = 1/137.036 (fine structure constant) e² = α·ħc = 1.43996 MeV·fm (Coulomb coupling)

The two-body Hamiltonian separates into centre-of-mass (free particle, ignored) and relative Hamiltonian. Charges Z₁, Z₂ enter the Coulomb potential: V_C(r) = Z₁Z₂e²/r = Z₁Z₂·α·ħc/r.

2 · Radial Schrödinger Equation

Writing ψ(r,θ,φ) = u(r)/r · Y_ℓm(θ,φ), the reduced radial function u(r) satisfies:

d²u/dr² = f(r)·u(r) f(r) = (2μ/ħ²)[V_eff(r) − E] = (2μ/(ħc)²)[V_eff(r) − E] × (ħc)² compensation V_eff(r) = V(r) + ħ²ℓ(ℓ+1)/(2μr²) [centrifugal barrier] = V(r) + (ħc)²ℓ(ℓ+1)/(2μc²·r²) Boundary conditions: u(0) = 0 (regularity at origin, u ~ r^{ℓ+1} near r=0) u(r→∞) = 0 (bound state: normalizable) u(r→∞) ~ e^{ikr} (scattering: outgoing wave)

Key factor: In these units, 2μ/(ħc)² = 2μc²/(ħc)² where μc² is in MeV and ħc=197.327 MeV·fm, giving the conversion factor 1/(ħc)² = 1/38923.5 MeV⁻²·fm⁻² so that f(r) has units fm⁻².

3 · Numerov's Method

The radial equation has no first-derivative term (u'' = f·u). Numerov's algorithm exploits this for 6th-order accuracy with only 4th-order work per step:

Numerov recurrence: u_{n+1}(1 + h²f_{n+1}/12) = 2u_n(1 − 5h²f_n/12) − u_{n-1}(1 + h²f_{n-1}/12) Startup: u(0)=0, u(h) = h^{ℓ+1} (near-origin behaviour r^{ℓ+1}) Global error: O(h⁴) [4th-order global accuracy] Eigenvalue shooting: Scan E, evaluate F(E) = u(r_max) Sign change F(E₁)·F(E₂) < 0 → eigenvalue E* in [E₁,E₂] Bisect to tolerance ε = 10⁻⁸ (80 iterations max)

4 · Runge-Kutta 4 Method

Alternative to Numerov. Convert u'' = f·u to system: y₁=u, y₂=u', then:

dy₁/dr = y₂ dy₂/dr = f(r)·y₁ k₁ = h·F(rₙ, yₙ) k₂ = h·F(rₙ+h/2, yₙ+k₁/2) k₃ = h·F(rₙ+h/2, yₙ+k₂/2) k₄ = h·F(rₙ+h, yₙ+k₃) y_{n+1} = yₙ + (k₁ + 2k₂ + 2k₃ + k₄)/6 Global error: O(h⁴)

5 · WKB Approximation

WKB eigenvalues (Bohr-Sommerfeld): ∫_{r₁}^{r₂} p(r) dr = (n − ½)πħ, p(r) = √(2μ[E−V_eff(r)]) In MeV/fm units: ∫_{r₁}^{r₂} √(2μc²[E−V_eff(r)]) dr = (n−½)π·ħc (numerically: n = 0,1,2,...) WKB phase shift: δ_ℓ^WKB = ∫_{r₁}^∞ [k(r) − k_∞] dr − k_∞·r₁ + (ℓ+½)π/2 where k(r) = √(2μ[E−V_eff(r)])/ħc [fm⁻¹]

6 · Normalisation — Simpson's Rule

Normalisation condition: ∫₀^∞ |u(r)|² dr = 1 Simpson's 1/3 rule (composite): ∫ₐᵇ f(r) dr ≈ (h/3)[f(r₀) + 4f(r₁) + 2f(r₂) + 4f(r₃) + ... + f(rₙ)] Error: O(h⁴) per interval Expectation values (all computed by Simpson): ⟨r⟩ = ∫ u*(r)·r·u(r) dr ⟨r²⟩ = ∫ u*(r)·r²·u(r) dr ⟨p²⟩ = −ħ²∫ u*(r)·(d²u/dr²) dr = ∫ |u'(r)|² dr (after parts)

7 · Scattering Theory — Phase Shifts

Asymptotic radial WF (r → ∞, V→0): u_ℓ(r) → A·[cos(δ_ℓ)·j_ℓ(kr) − sin(δ_ℓ)·n_ℓ(kr)] where k = √(2μE)/ħc [fm⁻¹] Phase shift extraction (two-point matching at large r): tan(δ_ℓ) = [u(r₁)·j_ℓ(kr₂) − u(r₂)·j_ℓ(kr₁)] / [u(r₂)·n_ℓ(kr₁) − u(r₁)·n_ℓ(kr₂)] (uses regular j_ℓ and irregular n_ℓ spherical Bessel functions) S-matrix: S_ℓ = e^{2iδ_ℓ}, |S_ℓ|² = 1 (unitarity) Scattering amplitude: f(θ) = (1/2ik) Σ_ℓ (2ℓ+1)(S_ℓ−1)P_ℓ(cosθ) = (1/k) Σ_ℓ (2ℓ+1)e^{iδ_ℓ}sin(δ_ℓ)P_ℓ(cosθ) Differential cross section: dσ/dΩ = |f(θ)|² [fm²/sr] Total elastic cross section (optical theorem): σ_total = (4π/k²) Σ_ℓ (2ℓ+1)sin²(δ_ℓ) [fm²] σ_max_ℓ = 4π(2ℓ+1)/k² (unitarity limit, when δ_ℓ = π/2)

8 · Resonance Theory — Breit-Wigner

Resonance energy: E = E_R − iΓ/2 E_R = resonance energy (real part) Γ = decay width (FWHM of cross-section peak) τ = ħ/Γ = lifetime (from energy-time uncertainty ΔE·Δt ≥ ħ) Phase shift near resonance (Breit-Wigner): tan(δ_ℓ) = −Γ/2 / (E − E_R) δ_ℓ passes through π/2 at E = E_R (rapid π-jump) dδ_ℓ/dE|_{E=E_R} = 2/Γ (width from peak derivative) Cross section (Breit-Wigner): σ_ℓ(E) = 4π(2ℓ+1)/k² · (Γ/2)² / [(E−E_R)² + (Γ/2)²] Algorithm: scan phase shift δ_ℓ(E), find rapid π-jumps, extract E_R and Γ from peak of dδ/dE. Alternatively: complex energy contour (Siegert states).
