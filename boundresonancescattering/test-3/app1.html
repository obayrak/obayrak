Physics Model

This simulator solves the radial two-body Schrödinger equation for a central potential. The two particles have masses m₁ and m₂, and charges represented through atomic numbers Z₁ and Z₂. The motion is reduced to a one-body problem using the reduced mass:

μ = m₁m₂ / (m₁ + m₂)

The radial wavefunction is represented by u(r)=rR(r). The equation solved is:

- (ħ² / 2μ) d²u/dr² + [ V(r) + ħ² l(l+1)/(2μr²) ] u = E u

The term ħ² l(l+1)/(2μr²) is the centrifugal barrier. Internal calculations use MeV for energy, fm for radius, and MeV/c² for mass, with ħc = 197.3269804 MeV·fm.

What Is Computed?

Bound States

Bound states satisfy normalizable boundary conditions and have discrete energies in confining or attractive potentials. The code searches for eigenvalues using boundary mismatch / node behavior and refines them with bisection.

Resonance States

Resonances are quasi-bound states embedded in the continuum. Version 1 estimates them from sharp phase-shift structures and trapped-state behavior.

E ≈ Eᵣ - iΓ/2

Scattering States

For positive energies, the asymptotic radial solution is matched to extract the phase shift δl(E), from which the S-matrix and cross sections are obtained.

Expectation Values

For normalized bound states, the simulator computes:

⟨r⟩, ⟨r²⟩, ⟨1/r⟩, ⟨T⟩, ⟨V⟩, ⟨H⟩

Embedded User Manual

1) How to use this simulator

Choose particle masses, charges, angular momentum l, potential, numerical method, and solution mode. Then click Run Solver.

For best first tests, use:

  • Potential: Woods–Saxon or Harmonic Oscillator
  • Mode: Bound States
  • Method: Numerov
  • l = 0
2) Physical basis

This is a reduced-mass central-potential quantum model. Appropriate for:

  • nuclear cluster motion
  • proton–nucleus scattering
  • meson-like effective potentials
  • hydrogenic / Coulomb-like radial problems
3) Numerical methods used
  • Numerov (4th order): optimal for second-order Schrödinger equations — uses a 3-point recurrence with O(h⁴) accuracy
  • RK4: general-purpose 4th-order ODE integration via the classical Runge–Kutta scheme
  • WKB: semiclassical approximation using the Bohr–Sommerfeld quantization condition
  • FD Shooting (2nd order): explicit 3-point finite difference recurrence u[i+1] = (2−h²k²[i])u[i] − u[i−1]. Simpler than Numerov but O(h²) accurate; useful for comparison and didactic purposes
  • FD Matrix Diag. (direct): assembles the full tridiagonal Hamiltonian H = T + V on a reduced grid and finds eigenvalues directly via Sturm-sequence bisection, then recovers eigenvectors by inverse power iteration with the Thomas algorithm. Does not scan energies — gives the bound spectrum in one shot
  • Bisection: robust root-finding for shooting-based eigenenergies
  • Simpson integration: normalization and expectation values
4) Why this matters physically

Bound states reveal the allowed discrete spectrum and structure. Resonances reveal temporary trapping and decay widths. Scattering phase shifts and cross sections are directly related to experimentally observable collision behavior.
