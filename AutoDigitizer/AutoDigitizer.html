2 · Axis calibration
Axis scales

Use the affine model for scanned or photographed figures whose axes are not exactly horizontal/vertical. X1, X2 must lie on one line parallel to the x-axis, Y1, Y2 on one line parallel to the y-axis.

Coordinate system & special axes

Place O on the pole (centre) and P on a labelled ring at a known angle (e.g. where the r = 10 ring crosses the 0° spoke). Tool C places them in order and lets you drag them.

Place the three corners of the triangle; each corner is 100 % of one component.

Click two labelled ticks of the right axis. Then choose, per curve, which axis it belongs to:

X1, X2 calibrate the first segment. Place X3, X4 on two labelled ticks beyond the break.

Y1, Y2 calibrate the first segment. Place Y3, Y4 on two labelled ticks beyond the break.

Automatic calibration

Finds the plot frame, axis lines and ticks, reads the numeric tick labels (built-in OCR: digits, −, decimals, 1e5, 10n, ×10n), detects linear vs. logarithmic scales and fits all labels robustly. Outliers from misread labels are rejected automatically.

Panels (multi-plot figures)

Figures with several sub-plots: every bottom-axis/left-axis corner is a panel. Each panel keeps its own calibration, curves and exclusions.

Reference points

Press Place (or tool C) and click a tick mark of known value. Drag markers to refine; the loupe helps. Values accept 2.5e-3, 3×10^4, 10^-2; date axes accept 2021-03-15, 2021-03-15T12:00 or decimal years.

3 · Data extraction
Curves
Graph type

Use the extraction tools below. For other chart types choose them here.

Pick the bar fill colour (I). Each bar gives position, edges, base and height; touching histogram bins are split where the height changes. Stacked bars: one curve per colour — the height is the segment size, y the cumulative top.

Pick the outline colour (empty = dark lines). Reads whiskers, quartiles and median of every box; separate dots become an outlier curve.

Pick the band's fill colour. Each column gives the upper and lower edge.

1) Find the colour bar, 2) enter z at its two points, 3) extract. The plot frame (or a region drawn with R) is sampled on a grid; regular heatmap cells are detected automatically.

Extract the line with the tools below (skeleton tracing works best for closed contours). Every point is exported with this z.

Accuracy checks

Redraws every curve from its extracted points (same line width, markers, bars or colours) and compares it pixel by pixel with the image.

Automatic extraction

Markers joined by lines: set an opening radius (Filtering) larger than half the line width to detach them.

Filtering & noise

Exclusion zones (tool X) remove legends, labels and annotations from every curve's mask.

Legend, line styles & crossings

Legend names are read with Tesseract OCR (loaded on demand, needs internet); otherwise the legend text image is shown next to the curve. Crossings: with the Guide tool (G) click the correct branch after a crossing — the click becomes an anchor and the curve is re-extracted along it.

Manual & semi-automatic

Manual (A): click to add, drag to move, Alt disables snapping. P adds a point at the cursor. Arrow keys nudge selected points (Shift ×10, Alt ×0.1).

Semi-automatic trace (T): click a start point and an end point on the curve. A least-cost path through matching pixels is found (Dijkstra) and sampled.

Graph recognition

Detection is heuristic (run-length, projection and connected-component analysis). Review overlays and correct with the region/exclusion tools.

4 · Data analysis
Display

Click a point to select it in the table. Box/lasso selection selects several. The image is placed by inverting the calibration, so misalignment reveals calibration errors.

Interpolation

Interpolants pass through every point (R² = 1 trivially), so they are compared by leave-one-out cross-validation RMSE.

Weighting & uncertainty
Confidence & prediction bands

The 95 % confidence intervals of the parameters are listed in the results table.

Models

Tests all library models, polynomials (degree 1–6) and multi-peak sums; picks the simplest model the data support. Or choose models manually:

Variable x; every other name is a fit parameter. Functions: exp log ln log10 sqrt sin cos tan asin acos atan atan2 sinh cosh tanh abs pow erf min max; constants pi, e; powers with ^.

The box can be dragged on the graph and is included in PNG/SVG export.
