The time-independent Schrödinger equation
Everything starts from the TISE: the Hamiltonian operator Ĥ acting on a stationary state Ψ returns that state scaled by its energy eigenvalue E.
Ĥ Ψ = E Ψ
1
Expand the Hamiltonian
In QM the momentum operator is p̂ = −iħ∇. Kinetic energy T = p²/2m* becomes −ħ²∇²/2m*. For a 2D electron confined in a quantum dot (z-motion frozen in its lowest subband) the TISE in the plane is:
−ħ²2m* ∇²2D Ψ(r,φ) + V(r) Ψ(r,φ) = E Ψ(r,φ)
2
Natural units: eV · nm
Multiply and divide by c² to replace ħ with the product ħc = 197.327 eV·nm and express mass as m*c² in eV. This eliminates 10⁻³⁴ factors and keeps everything in human-scale numbers.
T̂ = −(ħc)²2 m*c² ∇²2D     eV·nm² / nm² = eV ✓
In the code:  const HBARC = 197.3269804 (eV·nm)  and  const M0EV = 0.511e6 (eV/c²).
Effective mass in energy units: const mw = mstar * M0EV → m*c² in eV.
ħc
197.327 eV·nm
The most useful constant in condensed-matter QM. Eliminates all 10⁻³⁴ factors. Code: HBARC.
m*
Band effective mass
Carriers respond to forces via band curvature, not free mass. GaAs: 0.063 m₀. Kane formula from k·p theory. Code: mstar * M0EV.
V(r)
Potential energy
Rotationally symmetric — depends only on r. User-selectable: Fermi, square well, harmonic, Coulomb, Woods-Saxon, Morse, Gaussian.
E
Eigenvalue (energy)
Found by bisection. Bound states require E < V(∞). Only discrete values give normalizable solutions — this is quantization.
Boundary conditions: Ψ must be normalizable — decay to zero as r → ∞. At r = 0 it must be finite (zero for m_l ≥ 1). These two simultaneous constraints force E to take only discrete values: the energy spectrum.
2D cylindrical reduction and the Langer substitution
The quantum dot is modeled as a 2D disk — electrons move in the x-y plane, z is frozen. We exploit the rotational symmetry to reduce the 2D PDE to a 1D ODE.
1
2D Laplacian in polar coordinates (r, φ)
∇²2D = 1r ∂∂r(r ∂∂r)  +  1r² ∂²∂φ²
2
Separation of variables: Ψ(r, φ) = R(r) · eimlφ
Since V depends only on r, angular momentum m_l is a good quantum number. Single-valuedness Ψ(φ+2π) = Ψ(φ) forces m_l ∈ ℤ. Using ∂²eim_l φ/∂φ² = −m_l² eim_l φ and expanding:
−(ħc)²2m*c²  [  R″ + 1rR′ − m_l²r²R  ] + V(r)R = ER
The R′/r first-derivative term prevents direct use of Numerov's method, which requires the form u″ = f(r)·u. We must eliminate it.
3
The Langer substitution: R(r) = u(r) / √r
Define u(r) = R(r) · √r — this is the function the solver computes and the chart labels "u(r)". Compute derivatives:
R = u/√r    R′ = u′/√r − u/(2r3/2)    R″ = u″/√r − u′/r3/2 + 3u/(4r5/2)
Substitute into the radial equation and multiply through by √r. The R′/r term cancels exactly, and after collecting what remains:
u″(r) = − 2m*c²(ħc)²  [ E − Veff(r) ] · u(r)
4
The 2D Langer correction: (m_l² − ¼)
After the substitution, the centrifugal barrier acquires a correction. In 2D the effective angular barrier is:
Vcentrifugal(r) = (m_l² − ¼)(ħc)²2m*c² r²   ← 2D Langer, NOT m_l²
In 3D spherical coordinates it would be l(l+1). The −¼ correction arises because the 2D volume element is r dr dφ (not r² sin θ dr dθ dφ). Omitting it gives wrong energies even for m_l = 0.
In the code (line Vcent_coeff):
const Vcent_coeff = (l - 0.25) * hc2 / (2 * mw)
where l is m_l, hc2 = HBARC², mw = m*c².
For 3D it would be: l * (l + 1) * hc2 / (2 * mw)
Why not 3D? The dot is a flat disk grown epitaxially. z-confinement energy is large (~0.1 eV) and frozen — only 2D in-plane motion remains. This changes both the Laplacian form and the centrifugal correction. One line in the code switches between 2D and 3D geometry.
The full effective potential Veff(r) with magnetic field
Three physically distinct contributions enter Veff. The solver computes all three at every grid point before stepping the wavefunction. This is the code's veff(r) function.
Veff(r) = Vwell(r) + Vcentrifugal(r) + Vmagnetic(r)
1
Term 1 — Vwell(r): the user-selected confining potential
The attractive well that creates bound states. Encoded as pot(r, potParams) in the solver. Seven choices are available; each appears as Vbare in the chart (amber dashed line).
Fermi-Step
GaAs Γ–X band offset. Soft sigmoid interface.
Square Well
Hard-wall flat bottom. Discontinuous boundary.
Harmonic
Parabolic. Only exactly solvable 2D potential.
Coulomb
−k/r. Hydrogen atom, donors, excitons.
Woods-Saxon
Nuclear shell model. Smooth surface diffuseness.
Morse / Gaussian
Molecular / soft well. Fully numerical.
2
Term 2 — Vcentrifugal(r): 2D Langer angular barrier
Vcentrifugal(r) = (m_l − ¼)(ħc)²2m*c² · r²
Repulsive for m_l ≥ 1. Pushes the wavefunction outward, raises the energy, and creates a centrifugal barrier at small r. For m_l = 0 the −¼ correction gives a tiny attractive shift — this is a purely quantum effect absent in 3D. Singular at r = 0, so the code clamps r → max(r, 1e-9).
3
Term 3 — Vmagnetic(r): diamagnetic confinement
A magnetic field B along z is included via the symmetric gauge A⃗ = B/2 · (−y, x, 0). The full Hamiltonian with a magnetic field is:
Ĥ = 12m*(p̂ − eA⃗)² + V(r) =  p²2m* − e2m*L̂·B⃗ + e²B²8m*r² + V(r)
The middle term −(e/2m*)L̂·B is the paramagnetic (Zeeman) term. In the eigenstate of L_z it contributes a constant −(eħ/2m*)m_l B = −½ħω_c m_l, which simply shifts E and does not affect the wavefunction shape. The last term is the diamagnetic term:
Vmagnetic(r) = e²B²8m*r² = 18m*c²c²ωc² r²   ω_c = eB/m* (cyclotron freq.)
In the code:
const oc = EC * B / mwkg    // ω_c in rad/s
const Vmag_coeff = 0.125 * mw / (CNM*CNM) * oc*oc    // eV/nm²
function vmag(r) { return Vmag_coeff * r * r; }
The factor 1/c² converts kg·rad²/s² → eV/nm² by dividing by (nm/s)².
4
Complete k²(r) — the local wavenumber squared
k²(r) is the quantity Numerov propagates. Where k² > 0: oscillating (classically allowed). Where k² < 0: exponentially decaying (forbidden / tunneling). A bound state must have k² < 0 at large r so u → 0.
k²(r) = 2m*c²(ħc)²  [ E − Veff(r) ]
Code implementation:
const twoMwHc2 = 2 * mw / (HBARC * HBARC)
function k2(r, E) { return twoMwHc2 * (E - veff(r)); }
The ODE to solve and eigenvalue search
After the 2D reduction, Langer substitution, and assembly of Veff, the radial Schrödinger equation is a second-order linear ODE in Sturm–Liouville form — no first-derivative term.
u″(r) = −k²(r) · u(r)
1
Boundary conditions
u(0) = 0 — regularity at origin (enforced analytically; all states have R(0) finite, so u = R√r → 0).  u(r_max) → 0 — normalizability at infinity. The seed u(h) = 1 is arbitrary since the ODE is linear and homogeneous; normalisation is applied after the eigenvalue is found.
2
Eigenvalue search: bisection + Sturm node counting
For a random trial energy E, Numerov propagates u from r = 0 outward. The solution generally diverges at r_max — it only decays to zero at the discrete eigenvalues. The solver uses Sturm's oscillation theorem:
The n-th bound state (n = 0, 1, 2, …) has exactly n nodes (zero crossings). The node count is a monotone non-decreasing integer function of E. Bisection on [E_min, E_max] converges reliably by halving the interval until the target node count is isolated.
Convergence: from a 40 eV window to ΔE < 10⁻¹⁰ eV takes ⌈log₂(40/10⁻¹⁰)⌉ ≈ 45 bisection steps. The code runs up to 200 iterations.
3
Normalisation of u(r)
The Langer substitution R = u/√r gives the 2D norm condition ∫|R|² r dr = ∫u² dr = 1. After bisection, the code normalises u with a rectangle-rule sum:
let s = 0;
for (let i = 0; i <= N; i++) s += psi[i] * psi[i];
const norm = 1 / Math.sqrt(s * h);   // h = grid step in nm
4
Full solve() function
function solve(nr, Emax, Emin, rmin, rmax, N) {
  const h = (rmax - rmin) / N;           // grid spacing in nm
  let ehi = Emax, elo = Emin;

  // Bisection: isolate the nr-th bound state by node count
  for (let it = 0; it < 200; it++) {
    const En = (ehi + elo) * 0.5;
    const psi = runNumerov(En, rmin, h, N);
    if (countNodes(psi, N) > nr) ehi = En; else elo = En;
    if (ehi - elo < 1e-10) break;
  }

  const En = (ehi + elo) * 0.5;          // eigenvalue
  const psi = runNumerov(En, rmin, h, N);  // final wavefunction

  // Normalise: ∫u² dr = 1  (rectangle rule)
  let s = 0;
  for (let i = 0; i <= N; i++) s += psi[i] * psi[i];
  const norm = 1 / Math.sqrt(s * h);

  return { En, norm, pts };
}
Numerov's method vs Runge-Kutta 4
Both methods propagate u(r) forward in r. They differ in accuracy per function evaluation and in which equations they apply to.
1
Numerov's recurrence — where O(h⁶) comes from
Taylor-expand u(r+h) and u(r−h) around r. Use the ODE u″ = −k²u twice — once forward and once backward — to replace u″ with −k²u at each point. Adding forward and backward expansions, terms through h⁵ cancel by symmetry, leaving only the h⁶ local truncation error:
un+1 = 2(1 − 5h²k²n/12)un − (1 + h²k²n−1/12)un−1 1 + h²k²n+1/12 + O(h6)
The denominator uses k²n+1 at the next point — this makes Numerov implicit. Because the equation is linear in u, no iteration is needed: k²n+1 is evaluated from the potential (not from un+1), so it reduces to a single division.
Code: one Numerov step
const kn2 = k2(rmin + (n+2)*h, En);
psi[n+2] = (2*(1 - 5*h2/12*kn1)*psi[n+1]
- (1 + h2/12*kn)*psi[n])
/ (1 + h2/12*kn2);
kn = kn1; kn1 = kn2;  // slide 3-point window
2
Runge-Kutta 4 — four-stage scheme
RK4 works on any first-order ODE system. To apply to u″ = −k²u, rewrite as two coupled equations: v = u′ and v′ = −k²u. Four evaluations per step:
k₁ = h·f(rₙ, uₙ, vₙ)
k₂ = h·f(rₙ+h/2, uₙ+k₁ᵤ/2, vₙ+k₁ᵥ/2)
k₃ = h·f(rₙ+h/2, uₙ+k₂ᵤ/2, vₙ+k₂ᵥ/2)
k₄ = h·f(rₙ+h, uₙ+k₃ᵤ, vₙ+k₃ᵥ)
uₙ₊₁ = uₙ + (k₁ᵤ + 2k₂ᵤ + 2k₃ᵤ + k₄ᵤ)/6 + O(h⁵)

Key result: both methods achieve O(h⁴) global accuracy, but Numerov uses 1 function evaluation per step vs RK4's 4. For the same computational cost Numerov is ~4× more accurate on u″ = f·u. The gain is "free" — it exploits the absence of a u′ term.
4
Live benchmark — 2D harmonic oscillator (exact eigenvalue known)
The 2D harmonic oscillator ground state (m_l = 0) has E₀ = ħω exactly. We run both methods at the exact E and measure |u(r_max)| — which should be zero. Smaller residual = better accuracy.
When to use RK4 instead of Numerov: if the equation contains a u′ term — e.g. position-dependent effective mass m*(r) (BenDaniel-Duke), spin-orbit coupling, logarithmic r-grid for Coulomb problems, or time-dependent propagation. In those cases RK4 or higher-order general methods are needed.
