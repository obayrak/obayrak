# Orhan Bayrak - Interactive Physics Laboratories

Static GitHub Pages site (185 pages, 184 interactive apps), migrated from https://sites.google.com/view/obayrak

- `index.html` home page (atomic clock, physics visualisations, Ataturk portrait, lab cards)
- `about/` profile page (images/obayrak.jpg)
- `<lab>/<module>/index.html` page shell, `app1.html` the original interactive app (unchanged)
- `assets.css`, `assets.js`, `assets/clock.js` shared design and scripts
- `images/` site images, `404.html` not-found page, `.nojekyll`

Publish: Settings -> Pages -> Deploy from a branch -> main / (root).
