Theory Reference

Mathematical foundations, convergence orders, and error analysis for all implemented methods

Σ Error Analysis FundamentalsCHAPTER 0

Every numerical result carries two independent sources of error that a student must be able to tell apart.

Absolute error
$e=|x_{approx}-x_{true}|$
Relative error
$|e/x_{true}|$

Truncation error — comes from approximating an infinite/exact process (a derivative, an integral) with a finite formula. Governed by the Taylor remainder and shrinks as $h\to0$: $O(h^p)$.

Round-off error — comes from finite machine precision. Double precision has machine epsilon $\varepsilon_m\approx2.22\times10^{-16}$; every arithmetic operation can lose ~1 ulp. Round-off grows as $h\to0$ because you divide a tiny (noisy) numerator by a tiny $h$.

$$E_{total}(h)\approx C_1h^p+\frac{C_2\,\varepsilon_m}{h^q}$$

This is why every error-vs-h plot in this simulator is U-shaped: truncation dominates for large $h$, round-off dominates for very small $h$, and there is a sweet-spot $h_{opt}$ in between (see Chapter 2).

Order of convergence $p$ of a sequence $x_n\to x^*$ is defined by

$$\lim_{n\to\infty}\frac{|e_{n+1}|}{|e_n|^{p}}=C\;(\text{finite, nonzero})$$

$p=1$: linear (error shrinks by a constant factor each step). $p=2$: quadratic (correct digits roughly double every step) — this is why Newton's method is so fast near a simple root.

⌀ Root FindingCHAPTER 1

Given $f(x)$, find $x^*$ such that $f(x^*) = 0$.

Bisection Method — requires a bracket $[a,b]$ with $f(a)\cdot f(b)<0$; the Intermediate Value Theorem then guarantees a root inside (for continuous $f$).

$$c_n = \frac{a_n + b_n}{2}, \quad e_n \le \frac{b-a}{2^n}$$
Convergence
Linear O(1/2ⁿ)
Derivative needed
No

Slow but never diverges once a valid bracket is supplied — the safest fallback method.

Newton-Raphson — linearises $f$ at $x_n$ and finds where the tangent line crosses zero.

$$x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}$$
Convergence
Quadratic O(eₙ²)

Failure modes: $f'(x_n)\approx0$ blows up the step; a poor $x_0$ can overshoot into a different basin or diverge entirely; multiple/near-double roots degrade the rate to linear.

Secant Method — replaces $f'(x_n)$ with a finite-difference slope through the last two iterates, so no analytic derivative is required.

$$x_{n+1} = x_n - f(x_n)\frac{x_n - x_{n-1}}{f(x_n)-f(x_{n-1})}$$

Superlinear convergence $p=\phi\approx 1.618$ (the golden ratio) — almost as fast as Newton, at only one function evaluation per step instead of two (f and f').

Stopping criteria used by the simulator: stop when $|f(x_n)|<\varepsilon_{tol}$ or $|x_{n+1}-x_n|<\varepsilon_{tol}$, whichever the method hits first, up to Max Iter.

∂ Finite DifferencesCHAPTER 2

Taylor expansion: $f(x\pm h) = f(x)\pm hf'+\tfrac{h^2}{2}f''\pm\tfrac{h^3}{6}f'''+\cdots$

$$f'_{fwd}(x) = \frac{f(x+h)-f(x)}{h} + O(h)$$
$$f'_{cen}(x) = \frac{f(x+h)-f(x-h)}{2h} + O(h^2)$$
$$f''_{cen}(x) = \frac{f(x+h)-2f(x)+f(x-h)}{h^2} + O(h^2)$$

Central differencing is preferred whenever both neighbours are available: the odd-order Taylor terms cancel by symmetry, buying an extra order of accuracy for free.

MethodPointsOrder
Forward/Backward2O(h)
Central 1st2O(h²)
Central 2nd3O(h²)
5-point central5O(h⁴)

Five-point stencil (higher accuracy when $f$ is smooth and cheap to evaluate):

$$f'(x)=\frac{-f(x{+}2h)+8f(x{+}h)-8f(x{-}h)+f(x{-}2h)}{12h}+O(h^4)$$

Richardson extrapolation — combine two central-difference estimates at $h$ and $h/2$ to cancel the leading $O(h^2)$ error term and gain two more orders:

$$D=\frac{4D(h/2)-D(h)}{3}+O(h^4)$$

Why h can't be arbitrarily small: total error $\approx C h^2+\varepsilon_m/h$ for central differences. Minimising gives the optimal step

$$h_{opt}\approx\varepsilon_m^{1/3}\approx 10^{-5.3}\approx 6\times10^{-6}$$

Use the h-convergence button to see this U-shaped curve directly: error falls as $h^2$ (slope 2 on a log-log plot) until round-off takes over and the curve turns upward.

∫ QuadratureCHAPTER 3

Approximate $\int_a^b f(x)\,dx$ by sampling $f$ at $n{+}1$ equally spaced nodes, $h=(b-a)/n$.

$$T_n = \tfrac{h}{2}\!\left[f_0+2\sum_{i=1}^{n-1}f_i+f_n\right],\;E_T=-\frac{(b-a)h^2}{12}f''(\xi)$$
$$S_n = \tfrac{h}{3}\!\left[f_0+4f_1+2f_2+\cdots+f_n\right],\;E_S=-\frac{(b-a)h^4}{180}f^{(4)}(\xi)$$

Simpson's rule fits a parabola through every group of 3 points (needs $n$ even) — it integrates cubics exactly, which is why its error jumps two full orders above the trapezoidal rule for essentially the same cost.

$$R_{k,m}=R_{k,m-1}+\frac{R_{k,m-1}-R_{k-1,m-1}}{4^m-1},\;E=O(h^{2m+2})$$

Romberg integration is Richardson extrapolation applied repeatedly to trapezoidal estimates — each column of the table cancels one more error order.

RulePointsExact forError

Gauss-Legendre (n pts)ndegree ≤2n−1spectral

Gaussian quadrature (not implemented in this simulator, but important to know) chooses both node positions and weights optimally, so an $n$-point rule integrates polynomials up to degree $2n{-}1$ exactly — far more efficient than equally-spaced rules for smooth integrands.

Singular / improper integrands (e.g. $1/\sqrt{x}$, Bose-Einstein/Fermi-Dirac integrals): the lower limit is offset slightly above 0 (e.g. $a=10^{-3}$ or $10^{-6}$) to avoid evaluating $f$ at the singularity. This introduces a small, quantifiable truncation of its own — visible as a residual error even as $n\to\infty$.

⇌ 1st/2nd-Order IVPCHAPTER 4

Solve $y'=f(t,y)$, $y(t_0)=y_0$ on $[t_0,T]$ with step $h$ (2nd-order equations are reduced to a system in $y,v=y'$).

Forward Euler — take one step along the tangent line.

$$y_{n+1} = y_n + h\,f(t_n,y_n)$$
Local error
O(h²) per step
Global error
O(h) — 1st order

Global error is one order lower than local error because $\sim1/h$ steps are taken and their errors accumulate.

RK4 — averages 4 slope estimates (start, two midpoints, end) per step, matching the Taylor series to 4th order.

$$k_1=hf(t_n,y_n),\;k_2=hf\!\left(t_n+\tfrac{h}{2},y_n+\tfrac{k_1}{2}\right)$$
$$k_3=hf\!\left(t_n+\tfrac{h}{2},y_n+\tfrac{k_2}{2}\right),\;k_4=hf(t_n+h,\,y_n+k_3)$$
$$y_{n+1}=y_n+\tfrac{1}{6}(k_1+2k_2+2k_3+k_4)$$
Global error
O(h⁴) — 4th order

Numerical stability — apply a method to the Dahlquist test equation $y'=\lambda y$ ($\lambda<0$, decaying solution). Euler is stable only if

$$|1+h\lambda|<1\;\Longrightarrow\;h<\frac{2}{|\lambda|}$$

Take $h$ too large for a stiff/fast-decaying system and Euler's solution oscillates and blows up even though the true solution decays smoothly — the simulator flags this as "Divergence detected." RK4 has a larger stability region but is still explicit and conditionally stable; implicit methods (e.g. backward Euler, not implemented here) are unconditionally stable and needed for genuinely stiff systems (e.g. Van der Pol with large $\mu$).

⇌ BVP / EigenvalueCHAPTER 5

BVP: $y''=P(x)y'+Q(x)y+R(x)$ with conditions specified at both ends, discretised on $N$ mesh points with $h=(b-a)/N$.

$$\frac{y_{i-1}-2y_i+y_{i+1}}{h^2}=P_i\frac{y_{i+1}-y_{i-1}}{2h}+Q_iy_i+R_i$$

Leads to a tridiagonal linear system solved by the Thomas algorithm (an $O(N)$ Gaussian elimination special-cased for banded matrices). Global error $O(h^2)$.

This simulator implements Dirichlet conditions $y(a)=\alpha,\,y(b)=\beta$. Other common types: Neumann ($y'(a)=\alpha$, flux/slope specified) and Robin/mixed ($\alpha y+\beta y'=\gamma$, e.g. convective heat loss) — these change only the first/last rows of the tridiagonal system.

Numerov method for the 1-D time-independent Schrödinger equation $-\psi''+V\psi=E\psi$ (natural units $\hbar=m=1$):

$$\psi_{n+1}=\frac{2\psi_n(1-\tfrac{5h^2}{12}g_n)-\psi_{n-1}(1+\tfrac{h^2}{12}g_{n-1})}{1+\tfrac{h^2}{12}g_{n+1}}$$

where $g_n=E-V(x_n)$. Numerov achieves $O(h^4)$ from only a 3-point stencil because the equation has no first-derivative term — the trick cancels one extra Taylor order compared with a generic 2nd-order ODE.

Shooting for eigenvalues: integrate $\psi$ from the left boundary for a trial $E$; a physical bound state requires $\psi(b)\to0$. Scan $E$ for sign changes in $\psi(b)$, then bisect each bracket to refine the eigenvalue.

Physical read-out: the eigenvalues $E_n$ are quantized energy levels; the $n$-th eigenfunction has exactly $n$ nodes (zero crossings) inside the well — a good sanity check that the mode ordering in the results panel is correct.

Key insight: RK4 makes 4 function evaluations per step but achieves 4th-order accuracy. Euler makes 1 evaluation but only 1st-order accuracy. For the same computational cost, RK4 wins decisively — the same "more work per step, much faster convergence" logic applies to Simpson's vs. trapezoidal, and Newton vs. bisection.

Common pitfalls in this simulator

• Bisection error "f(a)·f(b) > 0": the bracket doesn't straddle a root — widen [a,b] or re-plot f(x) first.

• Newton/Secant diverge: initial guess $x_0$ too far from the root, or $f'\approx0$ nearby — try Bisection to localise the root first.

• Derivative h too small: error curve turns upward past $h_{opt}\sim10^{-5}$ — that's round-off, not a bug.

• Integral of a singular function looks "off": the offset lower limit (e.g. 0.001) truncates a small amount of the true improper integral — expected, not an error in the method.

• IVP "Divergence detected": step h is too large for the equation's stiffness — shrink h (see stability condition in Chapter 4).

• Eigenvalue solver finds too few/many modes: widen [E min, E max] or extend the domain [a,b] so ψ has fully decayed at the boundaries.
