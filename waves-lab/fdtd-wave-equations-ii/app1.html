Wave Equation — General Formulation

The wave equation is a hyperbolic second-order PDE governing the propagation of disturbances through a medium. It relates the second time-derivative of a scalar field to its spatial Laplacian:

∂²u/∂t² = c² ∇²u + f(x,t)
── where u = displacement, c = phase speed, f = source term

1D — String

∂²u/∂t² = c² ∂²u/∂x²
c = √(T/μ)
T = tension [N], μ = linear density [kg/m]

2D — Membrane

∂²u/∂t² = c²(uxx + uyy)
c = √(σ/ρₛ)
σ = surface tension [N/m]

3D — Acoustic

∂²p/∂t² = c²∇²p
c = √(γP₀/ρ)
γ = adiabatic index

EM — Maxwell

∂²E/∂t² = c²∇²E
c = 1/√(εμ)
c₀ = 3×10⁸ m/s in vacuo

Finite Difference Method — Leapfrog Scheme

Space and time are discretized uniformly: xᵢ = i·Δx, tⁿ = n·Δt. The central difference approximates second derivatives with O(h²) accuracy. The Leapfrog (Störmer-Verlet) scheme is time-reversible, symplectic, and conserves a discrete analog of energy.

Second-Order Central Differences

∂²u/∂t² ≈ (uᵢⁿ⁺¹ − 2uᵢⁿ + uᵢⁿ⁻¹) / Δt²
∂²u/∂x² ≈ (uᵢ₊₁ⁿ − 2uᵢⁿ + uᵢ₋₁ⁿ) / Δx²

1D Update Rule (Δx = Δt = 1)

uᵢⁿ⁺¹ = (2−γ)uᵢⁿ − (1−γ)uᵢⁿ⁻¹ + r²(uᵢ₊₁ⁿ − 2uᵢⁿ + uᵢ₋₁ⁿ)
r = c·Δt/Δx (CFL number), γ = damping coefficient

2D Update Rule

uᵢ,ⱼⁿ⁺¹ = (2−γ)uᵢ,ⱼⁿ − (1−γ)uᵢ,ⱼⁿ⁻¹
+ r²[ uᵢ₊₁,ⱼ + uᵢ₋₁,ⱼ + uᵢ,ⱼ₊₁ + uᵢ,ⱼ₋₁ − 4uᵢ,ⱼ ]

3D Update Rule

uᵢ,ⱼ,ₖⁿ⁺¹ = (2−γ)uᵢ,ⱼ,ₖⁿ − (1−γ)uᵢ,ⱼ,ₖⁿ⁻¹
+ r²[ Σ₆ neighbors − 6·uᵢ,ⱼ,ₖ ]

Truncation Error Analysis

Taylor expansion reveals the local truncation error:

τ = O(Δt²) + O(Δx²) → second-order convergence in both space and time

The modified equation introduces numerical dispersion: short wavelengths (near the Nyquist limit k·Δx ≈ π) propagate at a speed slightly different from c. This error scales as O(Δx²·k²).

CFL Stability Condition

The Courant-Friedrichs-Lewy condition is necessary for stability of explicit hyperbolic solvers. Physically, it requires the numerical domain of dependence to contain the analytical one.

1D Condition

r = c·Δt/Δx ≤ 1

Optimal choice: r ≈ 0.9
Instability at r > 1: exponential blow-up

2D Condition

r ≤ 1/√2 ≈ 0.707

Optimal: r ≈ 0.45
Two-direction propagation tightens bound

3D Condition

r ≤ 1/√3 ≈ 0.577

Optimal: r ≈ 0.28
Three directions → tightest constraint

For a general d-dimensional problem on uniform grids: r ≤ 1/√d.

r_max(d) = 1/√d → r₁ = 1.000, r₂ = 0.707, r₃ = 0.577

Boundary Conditions

Dirichlet — Fixed / Hard Wall

u|∂Ω = 0 (or prescribed value g(t))

Amplitude is forced to zero at the boundary. Corresponds to: string fixed at endpoints, drumhead clamped at rim, rigid acoustic wall (pressure antinode). Reflected wave has opposite sign → total reflection with phase inversion.

Neumann — Free / Soft Wall

∂u/∂n|∂Ω = 0 → ghost cell: u₋₁ = u₁

Zero normal derivative — no flux across boundary. Corresponds to: free end of rod, pressure-release surface (open pipe end), free edge of membrane. Reflected wave preserves sign.

Absorbing / Sponge Layer

σ(x) = σ_max · [(x−x₀)/δ]² for x ∈ [x₀, x₀+δ]
u_sponge = u · (1 − σ(x)·Δt)

A spatially varying damping coefficient σ(x) that ramps up near the boundary absorbs outgoing waves with minimal reflections. This is a simplified form of the Perfectly Matched Layer (PML) technique.

Periodic

u(x + L, t) = u(x, t) → u₀ = u_{N−1}, u_N = u₁

Domain wraps around — right edge connects to left. Models waves on a ring, crystal lattice, or periodic computational cell.

Absorbing (Mur First-Order)

uₓ|₀ = u_{1}ⁿ⁻¹ (one-way wave equation BC)

Based on the one-way wave equation ∂u/∂t + c·∂u/∂x = 0 at outflow boundaries. More accurate than sponge for plane waves.

Energy & Conservation

The undamped wave equation conserves total mechanical energy E = Eₖ + Eₚ:

E = ½∫∫∫[ρ(∂u/∂t)² + T·|∇u|²] dV = const

The discrete leapfrog scheme conserves a modified energy exactly (up to machine precision), making it superior to dissipative schemes for long-time integration. With damping γ > 0, energy decays exponentially: E(t) ~ E₀ · e^(−γt).

Normal Modes — 1D Dirichlet

uₙ(x,t) = sin(nπx/L)·cos(nπct/L), n = 1, 2, 3, …
fₙ = nc/(2L) → harmonic series

Normal Modes — 2D Rectangular

u_{mn}(x,y,t) = sin(mπx/Lₓ)·sin(nπy/Lᵧ)·cos(ω_{mn}t)
ω_{mn} = πc·√[(m/Lₓ)² + (n/Lᵧ)²]

Note: 2D modes are generally non-harmonic — the ratio ω_{mn}/ω_{11} is irrational for m ≠ 1 or n ≠ 1, producing complex inharmonic spectra (like a real drum).

Discrete Dispersion Relation

sin²(ωΔt/2) = r²·sin²(kΔx/2)
→ numerical phase speed c_num = (2/kΔt)·arcsin[r·sin(kΔx/2)]
→ c_num ≤ c (waves are always slowed, never sped up)
