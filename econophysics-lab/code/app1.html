ta_fa.py — AI quantitative dashboard generator

A single-file CLI that fetches market + fundamental data for any ticker, runs a full technical / fundamental / forecasting / risk / pattern-recognition / backtesting pipeline, and writes out one standalone, interactive HTML equity-research dashboard. This page explains the module and gives you a spot to drop in the source for easy copying.

01

What this module does

ta_fa.py is a single-file CLI tool: run it with a ticker and it fetches market + fundamental data, runs the full analysis pipeline below, and writes out one standalone, dependency-free HTML dashboard (Plotly-powered, tabbed, with live in-browser recalculators) — no server required after generation. python ta_fa.py --ticker AAPL

Data Engine

Market + fundamental data acquisition with graceful degradation.

  • OHLCV via yfinance, synthetic GBM fallback if offline
  • Fundamentals, peer comparables, earnings calendar
  • 5-year financial statements (balance sheet / income / cash flow)
  • Analyst price targets & rating actions

Technical Analysis

Pure pandas/numpy indicator library + composite scoring.

  • Trend: SMA/EMA, MACD, ADX, Aroon
  • Momentum: RSI, Stochastic, Williams %R, ROC
  • Volatility: Bollinger Bands, ATR, historical vol
  • Volume: OBV, MFI · weighted 0–100 technical score

Pattern Recognition

Rule-based structural analysis of price/volume geometry.

  • ~20 candlestick patterns with confidence scoring
  • Chart patterns (H&S, triangles, double tops, cup & handle…)
  • Support/resistance clustering, trendlines, channels
  • Breakout detection · Volume Profile (VPVR, POC/VAH/VAL)

Multi Time frame Analysis & Seasonality

Cross-timeframe confluence and calendar-effect statistics.

  • Daily/Weekly/Monthly trend agreement voting
  • Monthly seasonality (avg/median return, win rate)
  • Day-of-week seasonality

Fundamental Analysis

12 independent intrinsic-value models.

  • DCF (FCFF), FCFE, APV, EPV, Residual Income
  • DDM (single-stage, two-stage), H-Model, Graham Number
  • P/E, P/B, EV/EBITDA relative valuation
  • Reverse DCF · Fed Model · CAPM cost of equity · rate sensitivity

Credit Quality Analysis & friends

Fundamental strength & distress-risk cross-checks.

  • Piotroski F-Score (9-point), Altman Z-Score
  • Multi-year fundamentals trend, DuPont ROE decomposition
  • Interest coverage, Debt/EBITDA, current/quick ratio

Forecasting

Five independent price-projection methods.

  • Linear & polynomial regression
  • ARIMA, Holt-Winters exponential smoothing
  • 10,000-path Monte Carlo GBM simulation

Risk Analysis

Standard quant risk suite.

  • Beta, Sharpe, Sortino, max drawdown
  • Historical & parametric VaR, Expected Shortfall
  • Rolling beta/correlation · Kelly criterion sizing

Backtester & DashboardBuilder

Strategy simulation and final HTML assembly.

  • SMA-crossover backtest with commission/slippage/sizing
  • 8-tab Plotly dashboard: overview, technical, patterns, fundamental, forecasting, valuation, backtest, risk
  • Live in-browser DCF & position-size calculators (JS)
Design principle running through the file — nothing is fabricated. Any line item, indicator, or model input the data provider doesn't return is left as None and flagged as unavailable in the dashboard, rather than guessed or defaulted. Every card in the generated HTML also ships with a plain-language explanation of the formula and its assumptions.
