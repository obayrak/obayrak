Root Finding Methods

Bisection Method O(log₂ n)

The bisection method is the simplest and most robust root-finding algorithm. Given a bracket [a, b] where f(a)·f(b) < 0, the Intermediate Value Theorem guarantees a root exists. The algorithm repeatedly halves the interval.

$$x_{n+1} = \frac{a_n + b_n}{2}, \quad \text{update bracket based on sign of } f(x_{n+1})$$

Error bound after n iterations:

$$|x_n - x^*| \leq \frac{b - a}{2^n}$$
  • ✓ Pro Always converges if bracket is valid
  • ✓ Pro No derivative required
  • ▲ Con Slow — linear convergence only
  • ▲ Con Requires sign change in [a,b]
  • Order Linear — 1 bit of accuracy per step

Newton-Raphson O(n²) quadratic

Newton's method uses the tangent line at the current iterate to find the next approximation. It is derived from the first-order Taylor expansion of f around xₙ:

$$f(x) \approx f(x_n) + f'(x_n)(x - x_n) = 0 \implies x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}$$

Near the root, the error satisfies $|e_{n+1}| \approx \frac{|f''(x^*)|}{2|f'(x^*)|} e_n^2$, giving quadratic convergence.

  • ✓ Pro Quadratic convergence near root
  • ✓ Pro Doubles correct digits each iteration
  • ✗ Con Requires f'(x) — can use numerical diff
  • ✗ Con May diverge if f'(xₙ) ≈ 0 or bad x₀
  • Order Quadratic (p = 2)

Secant Method O(φ) ≈ 1.618

The secant method avoids computing derivatives by approximating f'(xₙ) using two previous iterates. It replaces the tangent with a secant line through (xₙ₋₁, f(xₙ₋₁)) and (xₙ, f(xₙ)):

$$x_{n+1} = x_n - f(x_n) \cdot \frac{x_n - x_{n-1}}{f(x_n) - f(x_{n-1})}$$

The convergence order is the golden ratio φ = (1+√5)/2 ≈ 1.618, giving superlinear but sub-quadratic convergence.

  • ✓ Pro No derivative required
  • ✓ Pro Superlinear convergence — faster than bisection
  • ✗ Con Needs two starting points x₀, x₁
  • ✗ Con Can fail if f(xₙ) ≈ f(xₙ₋₁)
  • Order Superlinear (p ≈ 1.618)
Numerical Differentiation

Finite Difference Formulas Taylor Series

All finite difference formulas are derived from Taylor expansions. Expanding f(x±h) and combining eliminates lower-order terms:

$$\text{Forward:}\quad f'(x) = \frac{f(x+h)-f(x)}{h} - \frac{h}{2}f''(\xi), \quad \xi \in (x,x+h)$$
$$\text{Backward:}\quad f'(x) = \frac{f(x)-f(x-h)}{h} + \frac{h}{2}f''(\xi)$$
$$\text{Central:}\quad f'(x) = \frac{f(x+h)-f(x-h)}{2h} - \frac{h^2}{6}f'''(\xi)$$
$$\text{2nd order:}\quad f''(x) = \frac{f(x+h)-2f(x)+f(x-h)}{h^2} - \frac{h^2}{12}f^{(4)}(\xi)$$
  • Forward/Back O(h) — error halves when h halves
  • Central O(h²) — error quarters when h halves
  • Caution Very small h causes catastrophic cancellation (floating-point)
  • Optimal h ≈ √ε for forward (ε = machine epsilon ≈ 10⁻¹⁶)
Numerical Integration

Trapezoidal Rule O(h²)

Approximates the integral by summing the areas of trapezoids formed by adjacent function values. For uniform spacing h = (b−a)/n:

$$\int_a^b f(x)\,dx \approx \frac{h}{2}\left[f(x_0) + 2\sum_{i=1}^{n-1}f(x_i) + f(x_n)\right]$$

The global error is $E_T = -\frac{(b-a)^3}{12n^2}f''(\xi)$, so doubling N reduces error by factor 4.

  • Order O(h²) — second order convergence
  • ✓ Pro Simple, robust, works for any continuous f
  • ▲ Con Slower convergence than Simpson

Simpson's 1/3 Rule O(h⁴)

Fits a quadratic polynomial through each pair of subintervals (requires even n). Uses coefficients 1-4-2-4-2-…-4-1:

$$\int_a^b f(x)\,dx \approx \frac{h}{3}\left[f(x_0) + 4f(x_1) + 2f(x_2) + 4f(x_3) + \cdots + f(x_n)\right]$$

Global error: $E_S = -\frac{(b-a)^5}{180n^4}f^{(4)}(\xi)$ — fourth-order convergence. Simpson is exact for polynomials up to degree 3 (superconvergence).

  • Order O(h⁴) — quartic convergence
  • ✓ Pro Much more accurate than Trapezoid for smooth f
  • ▲ Con N must be even; fails if f⁽⁴⁾ is large
Differential Equations

Euler Method O(h) global

The simplest ODE solver. Derived from truncating the Taylor expansion after the first term. For dy/dt = f(t, y), y(t₀) = y₀:

$$y_{n+1} = y_n + h\,f(t_n, y_n)$$

Local truncation error is O(h²), giving O(h) global error. The method is conditionally stable: for the test equation y' = λy, stability requires |1 + hλ| ≤ 1.

  • Order 1st order (global error O(h))
  • ✓ Pro Simplest possible; easy to understand
  • ✗ Con Accumulates error rapidly; may be unstable
  • Stability Conditionally stable — small h needed for stiff problems

Runge-Kutta 4 (RK4) O(h⁴) gold standard

The workhorse of ODE integration. Computes four slope estimates k₁…k₄ and takes a weighted average. This cancels all error terms up to h⁴:

$$k_1 = f(t_n,y_n),\quad k_2 = f\!\left(t_n+\tfrac{h}{2}, y_n+\tfrac{h}{2}k_1\right)$$
$$k_3 = f\!\left(t_n+\tfrac{h}{2}, y_n+\tfrac{h}{2}k_2\right),\quad k_4 = f(t_n+h,\,y_n+hk_3)$$
$$y_{n+1} = y_n + \frac{h}{6}(k_1 + 2k_2 + 2k_3 + k_4)$$
  • Order 4th order (global error O(h⁴))
  • ✓ Pro Excellent accuracy-per-step tradeoff
  • ✓ Pro Self-starting (no previous steps needed)
  • ▲ Con 4 function evaluations per step

Finite Difference Method (BVP) Linear System

For boundary value problems y'' + p(x)y' + q(x)y = r(x), replace derivatives with central differences at interior grid points xᵢ = a + ih:

$$y''_i \approx \frac{y_{i+1}-2y_i+y_{i-1}}{h^2}, \quad y'_i \approx \frac{y_{i+1}-y_{i-1}}{2h}$$

Substituting yields a tridiagonal linear system Ay = b, solved efficiently with the Thomas (TDMA) algorithm in O(N) operations.

  • Order O(h²) — second order in grid spacing
  • ✓ Pro Converts BVP to linear algebra
  • ✓ Pro Thomas algorithm: O(N) — very fast
  • ✗ Con Requires linear ODE for direct solve

Numerov Method O(h⁴) eigenvalue

Specialized for equations of the form ψ'' = f(x)ψ (Schrödinger, Bessel, etc.) with no first-derivative term. Uses a 3-point stencil that cancels the h² term:

$$\psi_{n+1}\!\left(1+\tfrac{h^2}{12}f_{n+1}\right) = 2\psi_n\!\left(1-\tfrac{5h^2}{12}f_n\right) - \psi_{n-1}\!\left(1+\tfrac{h^2}{12}f_{n-1}\right)$$

Eigenvalues are found via shooting: scan energy E until ψ(x_max) ≈ 0 (boundary condition), using bisection to isolate each eigenvalue bracket.

  • Order O(h⁴) — more accurate than standard FDM
  • ✓ Pro Perfect for quantum mechanics problems
  • ✓ Pro Shooting + bisection finds all bound states
  • ▲ Con Only works for equations without y' term
Convergence & Error Summary

Convergence Orders at a Glance

The order of convergence p means that when the step size h is halved, the error is reduced by a factor of 2ᵖ:

$$|e_{n+1}| \leq C \cdot |e_n|^p$$
  • p = 1 Linear — Bisection, Euler, Forward/Back Diff
  • p ≈ 1.6 Superlinear — Secant method
  • p = 2 Quadratic — Newton-Raphson, Trapezoid (in h), Central Diff (in h²)
  • p = 4 Quartic — RK4, Simpson, Numerov, 2nd Central Diff
  • Stiffness When λ-values of Jacobian span many orders — use implicit methods
  • Round-off Too small h causes catastrophic cancellation in finite differences
  • Optimal h Balance truncation vs round-off: h ≈ ε^(1/p) where ε ≈ 10⁻¹⁶
