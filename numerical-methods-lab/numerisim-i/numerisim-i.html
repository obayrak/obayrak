Theory Reference

Mathematical foundations, convergence orders, and error analysis for all implemented methods

⌀ Root FindingCHAPTER 1

Given \(f(x)\), find \(x^*\) such that \(f(x^*) = 0\).

Bisection Method

\[c_n = \frac{a_n + b_n}{2}, \quad e_n \le \frac{b-a}{2^n}\]
Convergence
Linear \(O(1/2^n)\)
Derivative needed
No

Newton-Raphson

\[x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}\]
Convergence
Quadratic \(O(e_n^2)\)

Secant Method

\[x_{n+1} = x_n - f(x_n)\frac{x_n - x_{n-1}}{f(x_n)-f(x_{n-1})}\]

Superlinear convergence \(p=\phi\approx 1.618\).
