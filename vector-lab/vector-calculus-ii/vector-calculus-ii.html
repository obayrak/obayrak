Vector Calculus — Physics Reference

∇f Gradient

The gradient of a scalar field f(x,y,z) is a vector field that at each point indicates the direction of steepest ascent and its rate. It generalizes the one-dimensional derivative to multiple dimensions.

∇f = (∂f/∂x) î + (∂f/∂y) ĵ + (∂f/∂z) k̂

Geometric interpretation

The gradient vector is always perpendicular to the level surfaces (isosurfaces) of f. Gradient lines are the paths of steepest descent — they cross every level surface at right angles. The magnitude |∇f| gives the local rate of change per unit distance.

Key identities

  • ∇(f + g) = ∇f + ∇g (linearity)
  • ∇(fg) = f∇g + g∇f (product rule)
  • ∇(f∘g) = (∇f ∘ g) · ∇g (chain rule)
  • ∇(constant) = 0
  • ∇f = 0 at all critical points (minima, maxima, saddle points)

Physical applications

Gravitational field
g = −∇φ (φ = gravitational potential)
Electric field
E = −∇V (V = electric potential)
Heat conduction
q = −k∇T (Fourier's law)
Pressure force
F/V = −∇P (hydrostatics)

∇·F Divergence

The divergence measures the net outflow of a vector field from an infinitesimal volume element. Positive divergence = source (fluid or field lines spreading out); negative divergence = sink (field lines converging).

∇·F = ∂Fx/∂x + ∂Fy/∂y + ∂Fz/∂z

Gauss's Divergence Theorem

The total divergence integrated over a volume V equals the net flux through its bounding surface S:

∯S F · dA = ∭V (∇·F) dV

This is one of the most powerful theorems in physics — it converts a surface integral into a volume integral, or vice versa.

Key identities

  • ∇·(F + G) = ∇·F + ∇·G (linearity)
  • ∇·(fF) = f(∇·F) + F·(∇f) (product rule)
  • ∇·(∇×F) = 0 (divergence of any curl is zero)
  • Solenoidal field: ∇·F = 0 (incompressible, divergence-free)

Physical applications

Gauss's law (E-field)
∇·E = ρ/ε₀ (charge = source of E)
Gauss's law (B-field)
∇·B = 0 (no magnetic monopoles)
Continuity equation
∂ρ/∂t + ∇·(ρv) = 0 (mass conservation)
Incompressible flow
∇·v = 0 (volume-preserving fluid)

∇×F Curl (Rotation)

The curl measures the local rotation of a vector field. At each point, it produces a vector whose direction is the axis of rotation (right-hand rule) and whose magnitude is twice the angular velocity of a tiny paddle wheel placed there.

∇×F = |î ĵ k̂| |∂/∂x ∂/∂y ∂/∂z| |Fx Fy Fz| = (∂Fz/∂y − ∂Fy/∂z) î + (∂Fx/∂z − ∂Fz/∂x) ĵ + (∂Fy/∂x − ∂Fx/∂y) k̂

Stokes' Theorem

The circulation of F around a closed curve C equals the flux of the curl through any surface S bounded by C:

∮C F · dr = ∬S (∇×F) · dA

Key identities

  • ∇×(F + G) = ∇×F + ∇×G (linearity)
  • ∇×(fF) = f(∇×F) + (∇f)×F (product rule)
  • ∇×(∇f) = 0 (gradient fields are irrotational)
  • ∇×F = 0 ⟹ F is conservative (path-independent work)

Physical applications

Faraday's law
∇×E = −∂B/∂t (changing B induces E)
Ampère–Maxwell law
∇×B = μ₀J + μ₀ε₀∂E/∂t
Vorticity (fluids)
ω = ∇×v (local angular velocity)
Angular velocity
For rigid body: ∇×v = 2ω

Fundamental vector calculus identities

∇×(∇f) = 0 Curl of any gradient is zero ∇·(∇×F) = 0 Divergence of any curl is zero ∇²f = ∇·(∇f) Laplacian of scalar ∇²F = ∇(∇·F) − ∇×(∇×F) Vector Laplacian ∇·(F×G) = G·(∇×F) − F·(∇×G) ∇×(F×G) = F(∇·G) − G(∇·F) + (G·∇)F − (F·∇)G

Maxwell's equations in differential form

∇·E = ρ/ε₀ (Gauss — electric) ∇·B = 0 (Gauss — magnetic) ∇×E = −∂B/∂t (Faraday) ∇×B = μ₀J + μ₀ε₀∂E/∂t (Ampère–Maxwell)

These four equations, expressed using gradient, divergence, and curl, encode all of classical electromagnetism.

Numerical differentiation

This tool uses the central difference formula for all partial derivatives:

∂f/∂x ≈ [f(x+h, y, z) − f(x−h, y, z)] / (2h)

This is a second-order accurate scheme: the truncation error is O(h²). The step size h can be adjusted using the parameter slider (default h = 0.001). Smaller h gives better accuracy for smooth functions but may introduce floating-point cancellation errors.

Error ≈ (h²/6) · f'''(x) (central difference, 2nd order)

Help & User Guide

Quick start

1. Select an operation (Gradient, Divergence, or Curl) using the three buttons at the top of the controls panel.

2. Enter your function(s) — one scalar function f(x,y,z) for gradient; three component functions Fx, Fy, Fz for divergence and curl.

3. Use the presets to load example functions instantly and explore canonical fields.

4. Set a point (x, y, z) to see exact computed values at that location.

5. Drag the 3D view to rotate, scroll to zoom, double-click to reset the camera.

Reading the visualization

Arrow direction — the direction of the computed vector (gradient direction, curl vector, or field direction for divergence).

Arrow length — proportional to the vector magnitude at that grid point. Adjust with the Arrow Scale slider.

Arrow color — follows the blue→green→yellow→red scale for magnitude. For Divergence mode, color encodes the divergence value (blue = sink, red = source) while arrow direction shows the field F.

Coordinate axes — red = x, green = y, blue = z (standard right-hand convention).

Parameter guide

ParameterEffect
Grid densityNumber of arrows per axis (n³ total). Increase for more detail.
Domain ±The spatial extent of the visualization (±R in each axis).
Arrow scaleVisual scaling factor for arrow length. Increase if arrows are too small.
Step hFinite difference step. Smaller = more accurate for smooth functions; larger = more stable for noisy functions.

Notes and limitations

Derivatives are computed numerically using the central difference formula with adjustable step h. For functions with discontinuities (e.g., 1/x near x=0), results near singularities may be inaccurate or NaN. The tool automatically skips NaN or infinite vectors in the visualization.
