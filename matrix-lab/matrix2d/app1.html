What Are Transformation Matrices?

In 2D computer graphics and robotics, geometric transformations — rotations, translations, reflections, scaling — are encoded as matrices. A point P = [x, y]ᵀ is transformed to a new position by left-multiplying with a transformation matrix M:

P' = M · P

The power of this formulation is that multiple transforms compose by matrix multiplication, making the order of operations precise and computationally efficient.

The 2D Rotation Matrix

To rotate a vector [x, y]ᵀ by angle θ counter-clockwise about the origin, we apply:

R(θ) = ⎡ cos θ −sin θ ⎤ ⎣ sin θ cos θ ⎦ x' = x·cos θ − y·sin θ y' = x·sin θ + y·cos θ

Key property: det(R) = cos²θ + sin²θ = 1 always. This means rotation is length-preserving (isometric) — it never stretches or compresses vectors. It is also orthogonal: R⁻¹ = Rᵀ.

The 2D Translation in Homogeneous Coordinates

Translation cannot be represented as a 2×2 matrix multiplication — it is an affine, not linear, transformation. The solution is to embed 2D space into a 3D projective space using homogeneous coordinates: a 2D point [x, y]ᵀ becomes [x, y, 1]ᵀ.

T(tx, ty) = ⎡ 1 0 tx ⎤ ⎢ 0 1 ty ⎥ ⎣ 0 0 1 ⎦ T · [x, y, 1]ᵀ = [x+tx, y+ty, 1]ᵀ ✓

Key property: det(T) = 1 always. Translation preserves area, shape, and orientation — it is a rigid-body motion.

Combined Transform & Order Matters

In homogeneous coordinates, rotation also becomes 3×3:

R_h(θ) = ⎡ cos θ −sin θ 0 ⎤ ⎢ sin θ cos θ 0 ⎥ ⎣ 0 0 1 ⎦ # Rotate-then-Translate: M = T · R_h → P' = T · (R_h · P) # Translate-then-Rotate: M = R_h · T → P' = R_h · (T · P)

⚠ Matrix multiplication is not commutative: T·R ≠ R·T in general. The two orderings produce geometrically distinct results — critical in robotics arm kinematics and 3D game engines.

Robotics & Kinematics

Robot arm joints are modeled as a chain of rotation matrices. Each joint's frame is expressed relative to the previous via Denavit-Hartenberg (DH) parameters — successive matrix multiplications from base to end-effector.

Computer Graphics (OpenGL)

Every shader pipeline applies Model × View × Projection matrices to each vertex. The GPU executes millions of 4×4 homogeneous matrix multiplications per frame to project 3D worlds onto 2D screens.

Quantum Mechanics

Rotation operators in quantum mechanics are represented by SU(2) matrices (spinors), generalizing SO(2) to include half-integer spins. Pauli matrices σₓ, σᵧ, σ_z are generators of this algebra.

Image Processing

Affine transformations (warp, skew, rotate, scale) of images are implemented as 2×3 matrices applied per-pixel. Perspective transforms (homographies) require the full 3×3 homogeneous form.

Determinant & Geometric Meaning

det(M) = signed area scaling factor det = +1 → area-preserving, orientation-preserving (proper rotation) det = −1 → area-preserving, orientation-reversing (reflection) |det| > 1 → expansion (volume grows) |det| < 1 → contraction (volume shrinks) det = 0 → singular: collapses to lower dimension

Eigenvalues of Rotation Matrices

The eigenvalues of R(θ) are e^(±iθ) — complex numbers on the unit circle. This confirms rotations have no real fixed-axis (for θ ≠ 0, π) in 2D, and their action is a pure rotation in the complex plane. The characteristic polynomial:

det(R − λI) = λ² − 2cos(θ)λ + 1 = 0 λ = cos(θ) ± i·sin(θ) = e^(±iθ) |λ| = 1 → stable, no growth or decay

Quick Start Guide

1
Select a Shape — In the left panel under "Shape", choose Triangle, Square, Arrow, or L-shape. The shape appears on the canvas grid centered at the origin. Each vertex is a column vector in the input matrix.
2
Set Transform Parameters — Use the θ slider to choose rotation angle (−180° to +180°). Use tx and ty sliders for translation components. Use s for uniform scale factor.
3
Choose Transform Order — R then T applies rotation first, then translates the rotated shape. T then R translates first, then rotates around origin. These produce different results — observe carefully.
4
Run the Animation — Click ▶ Animate to watch the shape morph through each transformation stage with interpolation. Use ⊳ Step to advance one stage at a time. Use ↺ Reset to return to the original.
5
Read the Matrix Display — Below the canvas, the full matrix equation is shown: R(θ) (cyan brackets) × input vectors (white) = result (green). Then the Translation matrix (orange) is applied.
6
Add Custom Points — Enter x and y values in the "Point Vector Input" fields and click + Add Point to append custom vertices. Use ✕ Clear to remove custom points and restore the default shape.
7
Right Panel Readouts — Shows original vector (P₀), vector after rotation (P₁), vector after translation (P₂). Below: det(R), det(T), det(M) properties confirm geometric meaning. det = 1 means area-preserving; det = scale² for scaled transforms.

Understanding the Matrix Equation Panel

The panel below the canvas renders the live matrix multiplication. Three column vectors are shown (one per vertex of a triangle, or centroid for complex shapes). The homogeneous 3×3 matrix is displayed in the right panel. The equation reads left-to-right:

[Transform Matrix] × [Input Vector] = [Output Vector] Rotation step: ⎡ cosθ -sinθ ⎤ ⎡ x ⎤ ⎡ x·cosθ - y·sinθ ⎤ ⎣ sinθ cosθ ⎦ × ⎣ y ⎦ = ⎣ x·sinθ + y·cosθ ⎦ Translation step (homogeneous): ⎡ 1 0 tx ⎤ ⎡ x' ⎤ ⎡ x' + tx ⎤ ⎢ 0 1 ty ⎥ × ⎢ y' ⎥ = ⎢ y' + ty ⎥ ⎣ 0 0 1 ⎦ ⎣ 1 ⎦ ⎣ 1 ⎦
