MIRROR & LENS FORMULA ▼

The fundamental formula for both mirrors and thin lenses (real-is-positive convention):

1/f = 1/dₒ + 1/dᵢ

Where f = focal length, dₒ = object distance, dᵢ = image distance. Magnification:

m = −dᵢ / dₒ = hᵢ / hₒ
  • f > 0: converging element (concave mirror, convex lens)
  • f < 0: diverging element (convex mirror, concave lens)
  • dᵢ > 0: real image (in front of mirror, or beyond lens)
  • dᵢ < 0: virtual image (behind mirror, or same side as object for lens)
  • |m| > 1: enlarged; |m| < 1: diminished; m < 0: inverted
CONCAVE MIRROR — CASES ▼

For a concave mirror (f > 0, C = 2f = centre of curvature):

  • dₒ > 2f: Real, inverted, diminished image between F and C
  • dₒ = 2f: Real, inverted, same-size image at 2f
  • f < dₒ < 2f: Real, inverted, magnified image beyond 2f
  • dₒ = f: Image at infinity (parallel reflected beam)
  • dₒ < f: Virtual, erect, magnified image behind mirror (like makeup mirror)
R = 2f (radius of curvature = 2 × focal length)
CONVEX MIRROR — PROPERTIES ▼

A convex mirror (f < 0) always produces a virtual, erect, diminished image regardless of object position.

  • Image always lies between pole and virtual focus F (behind mirror)
  • 0 < |m| < 1 always
  • Wide field of view → used in rear-view mirrors and security mirrors
CONVEX LENS — CASES ▼

For a converging (convex) lens, f > 0:

  • dₒ > 2f: Real, inverted, diminished image
  • dₒ = 2f: Real, inverted, same-size image at 2f
  • f < dₒ < 2f: Real, inverted, magnified image
  • dₒ = f: Rays exit parallel (image at infinity)
  • dₒ < f: Virtual, erect, magnified image (magnifying glass)
CONCAVE LENS — PROPERTIES ▼

A diverging (concave) lens (f < 0) always produces a virtual, erect, diminished image.

  • Image is always on the same side as the object (virtual, upright)
  • |m| < 1 always — image between object focal point and lens
  • Used in eyeglasses to correct myopia (nearsightedness)
LENSMAKER'S EQUATION ▼

Relates focal length to lens geometry and material:

(n − 1) × [1/R₁ − 1/R₂] = 1/f
  • n: refractive index of lens material (glass ≈ 1.5, crown glass ≈ 1.52)
  • R₁, R₂: radii of curvature of first and second surfaces
  • R > 0 if centre of curvature is on the transmission side
  • Biconvex: R₁ > 0, R₂ < 0 → f > 0 ✓ (converging)
  • Biconcave: R₁ < 0, R₂ > 0 → f < 0 ✓ (diverging)
SNELL'S LAW & REFRACTION ▼
n₁ sinθ₁ = n₂ sinθ₂

The refractive index n = c/v (speed of light in vacuum / speed in medium). Optical density increases with n.

  • n₂ > n₁: light bends toward normal (θ₂ < θ₁)
  • n₂ < n₁: light bends away from normal (θ₂ > θ₁)

Total Internal Reflection occurs when n₁ > n₂ and θ₁ exceeds the critical angle:

θ_c = arcsin(n₂ / n₁)

All incident light is reflected; no refracted ray exists. Used in optical fibres and prisms.

SPHERICAL ABERRATION ▼

Spherical surfaces do not bring all parallel rays to a common focus. Marginal rays (through outer zones) focus closer to the lens than paraxial rays (near the axis).

  • Paraxial focus: theoretical ideal focus for near-axis rays
  • Marginal focus: convergence point of outer rays (closer to lens)
  • Circle of least confusion: smallest beam cross-section between foci — best image plane
  • Longitudinal SA: distance between marginal and paraxial foci
  • Transverse SA: radius of blur circle in paraxial focal plane

Remedies: aspherical lenses, aperture stops (using only paraxial zone), achromatic doublets.

COMPOUND MICROSCOPE ▼

Two converging lenses: objective (short f, near specimen) + eyepiece (magnifier on intermediate image).

M_obj = −dᵢ / dₒ (real, inverted, magnified intermediate image)
M_eye = 25 / f_eye (eyepiece as simple magnifier, near point = 25 cm)
M_total = M_obj × M_eye ≈ (L / f_obj) × (25 / f_eye)

Where L = optical tube length (≈ distance between rear focal point of objective and front focal point of eyepiece). Standard L = 160 mm.

REFRACTING TELESCOPE ▼

Two converging lenses with shared focal plane (afocal system for infinite conjugates):

  • Objective: Large aperture, long focal length — forms real image of distant object at focal plane
  • Eyepiece: Short focal length — its front focal point coincides with objective's back focal point
  • Tube length = f_obj + f_eye
M = −f_obj / f_eye (angular magnification, inverted image)
Exit pupil = D_obj / |M|  |  f-ratio = f_obj / D_obj

High magnification requires large f_obj / f_eye ratio. Galilean telescope uses concave eyepiece (erect image, shorter tube).

⟨ OPTICS LAB — USER GUIDE ⟩

This simulator covers geometric optics, refraction, and optical instruments. All parameters are adjustable in real-time.

01

CALCULATOR TAB

Select optical element type (Convex/Concave Lens or Mirror). Adjust Object Distance (dₒ), Focal Length (f), and Object Height (h) with sliders. Results update instantly: image distance dᵢ, magnification m, image height hᵢ, and colour-coded property badges (Real/Virtual, Erect/Inverted, Magnified/Diminished).

02

2D RAY DIAGRAM TAB

Interactive ray diagram driven by Calculator parameters. Three principal rays are shown: Ray 1 (orange, parallel to axis), Ray 2 (green, through optical centre), Ray 3 (yellow, through focal point → parallel). Dashed lines = virtual rays or virtual image extensions. Toggle individual rays and labels on/off using the buttons.

03

3D VIEW TAB

Perspective 3D visualization. Rays fan out in 3D space from the object point, pass through the lens, and converge (or diverge) at the image. Drag the canvas to rotate. Scroll to zoom. Toggle ABERRATION to see how marginal rays focus at a different distance than paraxial rays (spherical aberration).

04

MICROSCOPE TAB

Simulate a compound microscope. Set Objective focal length (short: 2–10 mm), Eyepiece focal length (10–25 mm), Tube Length L, and Object Distance (must be slightly beyond f_obj). The app shows the two-stage magnification: objective forms a real intermediate image; eyepiece magnifies it further. Total M = M_obj × M_eye.

05

TELESCOPE TAB

Simulate a refracting telescope. Set Objective focal length (long: 100–300 mm), Eyepiece focal length (5–25 mm), and Aperture. Angular magnification M = −f_obj/f_eye is shown. Larger ratio = higher magnification. Also shows tube length, f-ratio, and exit pupil diameter.

06

ABERRATION TAB

Top canvas: Snell's Law — adjust n₁, n₂, and incident angle to see refraction. Red arrow indicates Total Internal Reflection when critical angle is exceeded. Bottom canvas: Spherical Aberration — shows how different height rays through the lens focus at different distances. Adjust aperture and aberration coefficient.

07

PHYSICS TAB

Complete reference for all formulas. Click any section header to expand/collapse. Covers: mirror/lens formula, image cases for all four element types, lensmaker's equation, Snell's law and total internal reflection, spherical aberration, compound microscope, and refracting telescope.

08

TIPS & KEY CASES

• Set dₒ = f for Calculator to see image at infinity (no convergence). • Move object inside focal length of concave mirror for virtual erect magnified image (makeup mirror). • For microscope: smaller f_obj = higher M_obj; aim for total M > 100×. • Set aberration coefficient to 0 for perfect lens; increase to see increasing blur. • Try Convex Mirror and note image is always virtual, erect, and smaller.
