Overview

This simulator models optical elements using the paraxial (thin-element) approximation. All physics follows the standard mirror and lens equations. Ray diagrams are drawn in real-time as you adjust parameters.

  • Select a simulation from the top navigation: Mirrors, Lenses, Microscope, Telescope
  • Use the Physics tab to read derivations, formulas, and detailed explanations
  • Toggle 2D / 3D to switch between flat and perspective views
2
Mirrors

Switch between Concave (converging) and Convex (diverging) mirrors. Three principal rays are drawn automatically.

  • Focal Length (f): Distance from mirror to focal point. Internally positive for concave, negative for convex.
  • Object Distance (dₒ): Try placing the object at f, 2f, and between them to observe the key cases.
  • Object Height (hₒ): Height of the object arrow above the principal axis.

Special positions to explore:

  • dₒ > 2f: Real, inverted, diminished image between f and 2f
  • dₒ = 2f: Real, inverted, same-size image at 2f
  • f < dₒ < 2f: Real, inverted, magnified image beyond 2f
  • dₒ → f: Image distance → ∞ (rays exit parallel)
  • dₒ < f: Virtual, upright, magnified image (magnifying glass effect)
3
Lenses

Switch between Converging (convex/biconvex) and Diverging (concave/biconcave). Same equation as mirrors.

  • Converging lens: same image cases as a concave mirror
  • Diverging lens: always produces a virtual, upright, diminished image (like convex mirror)
  • Lens Power shown in Diopters (D = 1/f in meters)
4
Microscope
  • Set fₒ (objective) short — e.g. 1–2 cm. Set uₒ slightly greater than fₒ for best magnification.
  • Set fₑ (eyepiece) to 5–10 cm. Total magnification = m_obj × m_eye.
  • Amber arrow: Intermediate real image between the lenses
  • Violet: Final virtual image (at near point 25 cm)
  • The diagram shows three rays from the object through the objective, then from the intermediate image through the eyepiece.
5
Telescope
  • fₒ: Long focal length objective (captures parallel rays from distant object)
  • fₑ: Short focal length eyepiece (magnifies intermediate image)
  • Angular magnification M = fₒ / fₑ. Separation = fₒ + fₑ.
  • The intermediate image forms at the shared focal plane. Exit rays are parallel (eye at rest).
  • Final image is inverted — standard for an astronomical (Keplerian) telescope.
6
Ray Color Legend
  • Amber: Ray parallel to axis → reflects/refracts through focal point F
  • Cyan: Ray through mirror pole or lens optical center → undeviated (lens) / symmetric reflection (mirror)
  • Red: Ray through/aimed at focal point → exits parallel to axis
  • White arrow: Object
  • Green arrow: Real image (solid)
  • Violet arrow: Virtual image (dashed)
  • — Solid lines = actual ray paths. – – Dashed lines = virtual extensions.
