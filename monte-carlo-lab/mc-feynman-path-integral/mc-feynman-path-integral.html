I. The Path Integral Formulation
In 1948, Richard Feynman reformulated quantum mechanics using a principle that particles do not travel a single definite path between two points — instead, they simultaneously explore all possible paths. The probability amplitude for propagation from $(x_a, t_a)$ to $(x_b, t_b)$ is computed by summing the phase factor $e^{iS/\hbar}$ over every conceivable path, where $S$ is the classical action functional.
Feynman Propagator (Real Time)
$$K(x_b, t_b;\, x_a, t_a) = \int_{x(t_a)=x_a}^{x(t_b)=x_b} \mathcal{D}[x(t)]\; e^{\,iS[x]/\hbar}$$
Each path $x(t)$ receives a complex amplitude $e^{iS/\hbar}$. Paths near the classical trajectory (which extremizes $S$) have nearby phases that add constructively, while random paths cancel by destructive interference. This recovers classical mechanics in the $\hbar \to 0$ limit.
II. The Classical Action Functional
Action
$$S[x(t)] = \int_{t_a}^{t_b} \mathcal{L}(x, \dot{x},t)\,dt = \int_{t_a}^{t_b}\!\left[\frac{m\dot{x}^2}{2} - V(x)\right]dt$$
The principle of stationary action $\delta S = 0$ selects the classical path satisfying the Euler–Lagrange equation $m\ddot{x} = -\partial V/\partial x$. Quantum corrections arise from paths with $S \sim \hbar$ around the classical extremum.
III. Wick Rotation & Euclidean Path Integrals
For Monte Carlo sampling, we perform a Wick rotation to imaginary time $\tau = it$, transforming the oscillatory factor $e^{iS/\hbar}$ into a real Boltzmann-like weight $e^{-S_E/\hbar}$ — the key to PIMC.
Euclidean Action
$$S_E[x(\tau)] = \int_0^{\beta\hbar}\!\left[\frac{m}{2}\!\left(\frac{dx}{d\tau}\right)^{\!2} + V(x)\right]d\tau, \qquad \beta = \frac{1}{k_BT}$$
Euclidean Propagator / Partition Function
$$Z = \int \mathcal{D}[x(\tau)]\; e^{-S_E[x]/\hbar} \;=\; \operatorname{Tr}\!\left[e^{-\beta\hat{H}}\right]$$
At low temperature ($\beta \to \infty$), the dominant contribution comes from the ground state: $Z \to e^{-\beta E_0}$. Path configurations sampled with weight $e^{-S_E}$ give direct access to quantum ground-state properties.
IV. Discretization & Monte Carlo
The imaginary-time interval $[0,\beta]$ is divided into $N$ slices of width $\varepsilon = \beta/N$. Each path becomes a sequence of positions $\{x_0, x_1, \ldots, x_N\}$.
Discretized Euclidean Action
$$S_E^{(N)} = \sum_{i=0}^{N-1}\left[\frac{m}{2\varepsilon}(x_{i+1}-x_i)^2 + \varepsilon\, V(x_i)\right], \qquad \varepsilon = \frac{\beta}{N}$$
The Metropolis algorithm generates paths distributed according to $e^{-S_E}$. Each step proposes a displacement of one time slice and accepts or rejects based on the change in local action, visiting only neighboring links.
# Metropolis sweep over all internal slices
for i in 1 … N-1:
  x_new = x[i] + δ × Uniform(−1, +1)
  ΔS = S_local(x_new) − S_local(x[i])
  if ΔS < 0 or rand() < exp(−ΔS): accept
  else: reject
Thermodynamic Energy Estimator
$$\langle E \rangle = \frac{N}{2\beta} - \left\langle \frac{1}{N}\sum_{i=0}^{N-1} \frac{m(x_{i+1}-x_i)^2}{2\varepsilon^2}\right\rangle + \left\langle\frac{1}{N}\sum_{i=0}^{N-1}V(x_i)\right\rangle$$
V. Quantum Systems
Free Particle
$V(x)=0$. Classical path is straight line. Quantum paths diffuse freely; spread $\propto\sqrt{\beta}$. Ground state is a plane wave.
Harmonic Oscillator
$V(x)=\frac{1}{2}m\omega^2 x^2$. Exact ground state energy $E_0=\frac{1}{2}\hbar\omega$. Classical path follows $\sinh(\omega\tau)$; paths form Gaussian distribution.
Double Well
$V(x)=\lambda(x^2-a^2)^2$. Quantum tunneling between wells. PIMC captures instanton paths (kink solutions) crossing the barrier.
Particle in a Box
$V(x)=0$ for $|x|<L$, $\infty$ otherwise. Paths confined to the box; energy levels $E_n=\frac{n^2\pi^2\hbar^2}{2mL^2}$. Ground state $\psi_0\propto\cos(\pi x/2L)$.

Quick Start
  1. Open the Simulation tab and choose a System.
  2. Press ▶ Run. Each path is pinned at $x_0 = x_N = 0$ and its internal slices are updated by Metropolis sweeps. A short equilibrating badge is shown during the first 80 steps.
  3. Watch $\langle E\rangle$ converge toward the exact reference value (shown when one is available) and compare the sampled density with the theoretical $|\psi_0|^2$.
  4. Open the Analysis tab for action, energy, histogram and acceptance-rate traces.
Controls
Path Ensemble
Paths sets how many independent paths are sampled. Time slices $N$ sets the discretization (changing $N$ or the system re-initializes all paths). $\beta$ is the total imaginary time; $\varepsilon = \beta/N$.
Potential Parameters
$\omega$ controls the harmonic potential, while $\lambda$ and $a$ set the depth and position of the double-well minima. Changes apply live; press Reset to re-equilibrate from scratch.
Monte Carlo
The step size $\delta$ is the maximum single-slice displacement. Speed is the number of Metropolis sweeps performed per animation frame.
Display
Toggle the classical path, the 2D density heatmap accumulated over all slices, slice markers (for $N \le 40$) and the glow effect.
Reading the Plots
  • Path ensemble: path colour reflects action — low-action paths are the most probable under $e^{-S_E}$ and are drawn brightest.
  • Position density: histogram of the mid-slice positions; the dashed curve is the analytic ground-state density where one exists (harmonic oscillator, box).
  • Acceptance rate: a rate above 60% suggests $\delta$ is too small, below 20% too large; roughly 30–60% is a good working range.
  • Energy: the thermodynamic estimator is noisy for large $N$; use the moving average (white/dark line) and a larger $\beta$ to approach the ground-state energy.
Tips
  • Use the ☾ Night / ★ Day buttons at the top right to switch themes; the choice is remembered in this browser.
  • For the double well, increase $\beta$ to see tunnelling kinks between wells; reduce $\lambda$ for easier barrier crossing.
  • Reducing the number of paths and the speed makes the simulation lighter on slower machines.
