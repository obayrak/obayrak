Both methods estimate the volume of a 3D region \(D\) by computing \(V = \iiint_D dV\), expressed as an integral of an indicator function \(I(x,y,z) = 1\) if \((x,y,z)\in D\), else \(0\), over the bounding box: $$V = \iiint_{\text{box}} I(x,y,z)\,dV$$ Monte Carlo estimates this integral stochastically; Simpson's rule estimates it deterministically on a grid. Below is the full derivation of each estimator, its error, and why they behave so differently in 3D.
1 Monte Carlo Integration
Random sampling reduces a geometry problem to a probability problem

1.1  Deriving the estimator

Draw \(N\) points uniformly at random inside the bounding box, which has known volume \(V_{\text{box}}\) (e.g. for a unit-cube bound, \(V_{\text{box}} = 2\times2\times2 = 8\)).
For each point \(i\), evaluate the indicator function: \(I_i = 1\) if the point lies inside the shape, \(I_i = 0\) otherwise. Each \(I_i\) is a Bernoulli random variable with success probability \(p = V / V_{\text{box}}\) (the true volume fraction).
The fraction of "hits" \(\hat p = N_{\text{in}} / N\) is an estimate of \(p\). Rescaling by the box volume gives the volume estimator actually used in the simulation:
$$\hat V = V_{\text{box}} \cdot \frac{N_{\text{in}}}{N} = V_{\text{box}} \cdot \frac{1}{N}\sum_{i=1}^{N} I_i$$

1.2  Why it's unbiased

Since each \(I_i\) is \(\text{Bernoulli}(p)\), its expectation is \(E[I_i] = p\). By linearity of expectation over the sum:

$$E[\hat V] = V_{\text{box}} \cdot \frac{1}{N}\sum_{i=1}^N E[I_i] = V_{\text{box}}\cdot p = V_{\text{box}}\cdot\frac{V}{V_{\text{box}}} = V$$

The estimator's expected value equals the true volume for any \(N\) — there is no systematic bias, only sampling noise, which is why the running estimate wanders around the true value rather than approaching it from one side.

1.3  Deriving the error: variance, standard error, confidence interval

For a \(\text{Bernoulli}(p)\) variable, \(\text{Var}(I_i) = p(1-p)\). The \(I_i\) are independent, so the variance of the sum scales linearly with \(N\):

$$\text{Var}(\hat V) = V_{\text{box}}^2 \cdot \text{Var}(\hat p) = V_{\text{box}}^2 \cdot \frac{p(1-p)}{N}$$

Taking the square root gives the standard error (with \(p\) replaced by its estimate \(\hat p\), since the true \(p\) is unknown):

$$SE = V_{\text{box}}\sqrt{\frac{\hat p(1-\hat p)}{N}}$$

By the Central Limit Theorem, for large \(N\) the sum of many independent Bernoulli trials is approximately normally distributed: \(\hat V \sim \mathcal{N}(V, SE^2)\). This justifies the 95% confidence interval reported live in the simulation:

$$CI_{95\%} = \hat V \pm 1.96\cdot SE$$
Convergence rate. Because \(SE \propto \sqrt{1/N}\), the error shrinks as \(O(N^{-1/2})\). To halve the error you must quadruple the number of samples — this is the characteristic, relatively slow, \(\sqrt{N}\) convergence of every Monte Carlo method.

1.4  Why Monte Carlo doesn't care about dimension

Nothing in the derivation above depended on the region being 3-dimensional — \(p\) is just "fraction of random trials that land inside," regardless of how many coordinates each trial has. The error formula \(SE \propto N^{-1/2}\) holds in 1D, 3D, or 30D alike. This is why Monte Carlo becomes the preferred method as dimensionality grows: grid-based quadrature needs roughly \(n^d\) evaluation points for a \(d\)-dimensional region sampled at resolution \(n\) per axis (the "curse of dimensionality"), while Monte Carlo's cost to reach a target error depends only on the error itself, not on \(d\).

2 Simpson's Rule (Grid Quadrature)
A deterministic rule built by fitting parabolas through sampled points

2.1  The 1D rule: fitting a parabola

Simpson's rule approximates \(\int_{x_0}^{x_2} f(x)\,dx\) by replacing \(f\) with the unique parabola passing through three equally spaced points \((x_0,f_0), (x_1,f_1), (x_2,f_2)\), spaced \(h\) apart. Integrating that parabola exactly (via Lagrange interpolation or the method of undetermined coefficients) yields:

$$\int_{x_0}^{x_2} f(x)\,dx \approx \frac{h}{3}\left[f_0 + 4f_1 + f_2\right]$$

Because a parabola matches \(f\) up to its 3rd derivative exactly, and by symmetry the 4th-order term also cancels, the local error is one order better than expected:

$$\text{Error}_{\text{local}} = -\frac{h^5}{90}f^{(4)}(\xi), \quad \text{for some } \xi \in [x_0,x_2]$$

2.2  Composite rule and its O(h⁴) accuracy

To integrate over the full domain \([a,b]\), split it into \(n\) (even) equal subintervals of width \(h = (b-a)/n\) and chain the 3-point rule across them. Interior points shared between neighboring panels get weight 4 (odd-indexed) or 2 (even-indexed), endpoints get weight 1 — the classic 1-4-2-4-2-…-4-1 pattern:

$$S = \frac{h}{3}\Big[f_0 + 4(f_1+f_3+\cdots) + 2(f_2+f_4+\cdots) + f_n\Big]$$

Summing the \(O(h^5)\) local errors over \(n = O(1/h)\) panels leaves a global error of \(O(h^4) = O(1/n^4)\) — provided \(f\) has 4 continuous derivatives. This is the fourth-order accuracy Simpson's rule is famous for.

2.3  Extending to 3D: the composite triple-Simpson formula

A volume integral separates into nested 1D integrals (Fubini's theorem), so the 1D rule can be applied once per axis. Each axis contributes its own \(h/3\) prefactor and its own 1-4-2-4…-1 weight sequence (\(w_i, w_j, w_k\)), giving the formula used in this simulation:

$$S = \frac{h_x h_y h_z}{27}\sum_i\sum_j\sum_k w_i w_j w_k \cdot I(x_i,y_j,z_k)$$

The \(1/27\) is simply \((1/3)^3\) — the product of the three \(h/3\) prefactors, one per axis. For a smooth integrand this formula would inherit the same \(O(h^4)\) accuracy as the 1D case.

2.4  Why shapes degrade this to O(1/n): the boundary discontinuity

The formula above is being applied to the indicator function \(I(x,y,z)\), which jumps abruptly from 0 to 1 across the shape's boundary surface. Simpson's rule assumes \(f\) behaves like a smooth quartic locally — a discontinuity violates that assumption for every grid cell that straddles the boundary. A short scaling argument shows exactly how much accuracy is lost:

The shape's boundary is a 2D surface with some fixed surface area \(A\).
With grid spacing \(h \sim 1/n\), each grid cell has a cross-sectional face of area \(\sim h^2\). The number of cells that the boundary surface passes through is therefore \(\approx A/h^2 \sim O(n^2)\).
Each straddling cell has volume \(h^3\), and the quadrature rule can misjudge that entire cell's contribution — contributing an error of order \(O(h^3)\) per cell.
Multiplying cell count by per-cell error: total error \(\sim O(n^2)\times O(h^3) = O(n^2 h^3)\). Since \(h = 1/n\), this is \(O(n^2/n^3) =\) \(O(1/n)\).
$$\text{3D Grid Error (on shapes)} \propto \frac{1}{n} \quad\text{instead of}\quad \frac{1}{n^4}$$
Result. The boundary discontinuity collapses fourth-order accuracy down to first order — the same order as a naive rectangle rule. This is why, for irregular 3D solids, Simpson's rule on a grid is no better (and often worse, given its \(n^3\) evaluation cost) than Monte Carlo.

2.5  The exception: smooth surfaces z = f(x,y)

When the "Custom Function" mode integrates the volume under an explicit, smooth surface \(z = f(x,y)\) rather than testing membership in a solid, there is no boundary discontinuity — \(f\) is continuous with as many derivatives as needed. The volume reduces to a 2D double integral, computed with a tensor product of two 1D Simpson rules:

$$S = \frac{h_x h_y}{9}\sum_i\sum_j w_i w_j \cdot f(x_i,y_j)$$

With no discontinuity to spoil the local Taylor expansion, the full fourth-order accuracy survives:

$$\text{Double-Simpson Error} \propto h^4 \propto \frac{1}{n^4}$$

This is why, for the custom-function case only, Simpson's rule converges dramatically faster than Monte Carlo — a modest grid (e.g. \(n = 40\) per axis, 1600 evaluations) can beat millions of random samples.

In short: Monte Carlo's \(\sqrt{N}\) convergence is dimension-agnostic and degrades gracefully; Simpson's rule's convergence is problem-dependent — spectacular (4th order) on smooth integrands, but knocked down to 1st order the moment a boundary discontinuity is introduced, while still paying the full grid cost of \(O(n^3)\) evaluations.

This self-contained Python script performs the exact same calculations as the simulation, comparing 3D Monte Carlo integration with Simpson's rule across different shapes.
monte_carlo_simpson_3d.py 
#!/usr/bin/env python3
"""
Monte Carlo vs Simpson's Rule for 3D Volume Estimation.
This script demonstrates numerical volume integration in 3D using two approaches:
1. Monte Carlo (Stochastic random sampling with confidence intervals)
2. Simpson's Rule (Deterministic composite quadrature grids)
"""

import math
import random
import sys

# ─── SHAPE EQUATIONS & DEFINITIONS ───

def is_inside_sphere(x, y, z):
    """Unit sphere: x^2 + y^2 + z^2 <= 1"""
    return x*x + y*y + z*z <= 1.0

def is_inside_ellipsoid(x, y, z):
    """Ellipsoid with semi-axes a=1.0, b=0.7, c=0.5: x^2 + (y/0.7)^2 + (z/0.5)^2 <= 1"""
    return x*x + (y/0.7)**2 + (z/0.5)**2 <= 1.0

def is_inside_torus(x, y, z):
    """Torus with major radius R=0.7, minor radius r=0.3: (R - sqrt(x^2 + y^2))^2 + z^2 <= r^2"""
    R = 0.7
    r = 0.3
    dist = R - math.sqrt(x*x + y*y)
    return dist*dist + z*z <= r*r

def is_inside_heart(x, y, z):
    """Taubin's 3D Heart: (x^2 + 2.25*y^2 + z^2 - 1)^3 - x^2 * z^3 - 0.1125 * y^2 * z^3 <= 0"""
    f = x*x + 2.25*y*y + z*z - 1.0
    return f**3 - x*x * z**3 - 0.1125 * y*y * z**3 <= 0.0

def custom_function(x, y):
    """Demo surface: z = sin(x) * sin(y) over x, y in [0, pi]"""
    if 0 <= x <= math.pi and 0 <= y <= math.pi:
        return math.sin(x) * math.sin(y)
    return 0.0

def is_inside_custom_fn(x, y, z):
    """Volume under the custom function surface z = f(x, y) above z = 0"""
    if z < 0:
        return False
    val = custom_function(x, y)
    return z <= val

# ─── INTEGRATION ENGINES ───

def monte_carlo_3d(inside_fn, bounds, n_samples):
    x_min, x_max = bounds["x"]
    y_min, y_max = bounds["y"]
    z_min, z_max = bounds["z"]
    
    vol_box = (x_max - x_min) * (y_max - y_min) * (z_max - z_min)
    inside_count = 0
    
    for _ in range(n_samples):
        rx = random.uniform(x_min, x_max)
        ry = random.uniform(y_min, y_max)
        rz = random.uniform(z_min, z_max)
        if inside_fn(rx, ry, rz):
            inside_count += 1
            
    p = inside_count / n_samples
    est_vol = p * vol_box
    
    if n_samples > 1:
        se = vol_box * math.sqrt(p * (1.0 - p) / n_samples)
    else:
        se = 0.0
        
    ci_margin = 1.96 * se
    return est_vol, se, (est_vol - ci_margin, est_vol + ci_margin)

def simpson_weights(n):
    return [1] + [4 if i % 2 != 0 else 2 for i in range(1, n)] + [1]

def simpson_3d_grid(inside_fn, bounds, n_div):
    if n_div % 2 != 0:
        n_div += 1
        
    x_min, x_max = bounds["x"]
    y_min, y_max = bounds["y"]
    z_min, z_max = bounds["z"]
    
    hx = (x_max - x_min) / n_div
    hy = (y_max - y_min) / n_div
    hz = (z_max - z_min) / n_div
    
    wx = simpson_weights(n_div)
    wy = simpson_weights(n_div)
    wz = simpson_weights(n_div)
    
    sum_val = 0.0
    for i in range(n_div + 1):
        x = x_min + i * hx
        w_i = wx[i]
        for j in range(n_div + 1):
            y = y_min + j * hy
            w_j = wy[j]
            for k in range(n_div + 1):
                z = z_min + k * hz
                w_k = wz[k]
                val = 1.0 if inside_fn(x, y, z) else 0.0
                sum_val += w_i * w_j * w_k * val
                
    return sum_val * (hx * hy * hz) / 27.0

def simpson_2d_double_integral(func, bounds_2d, n_div):
    if n_div % 2 != 0:
        n_div += 1
        
    x_min, x_max = bounds_2d["x"]
    y_min, y_max = bounds_2d["y"]
    
    hx = (x_max - x_min) / n_div
    hy = (y_max - y_min) / n_div
    
    wx = simpson_weights(n_div)
    wy = simpson_weights(n_div)
    
    sum_val = 0.0
    for i in range(n_div + 1):
        x = x_min + i * hx
        w_i = wx[i]
        for j in range(n_div + 1):
            y = y_min + j * hy
            w_j = wy[j]
            val = func(x, y)
            sum_val += w_i * w_j * val
            
    return sum_val * (hx * hy) / 9.0

# ─── MAIN SIMULATION RUNNER ───

def main():
    mc_samples = 100000
    simp_subdivisions = 40
    
    shapes = {
        "Sphere": {
            "inside_fn": is_inside_sphere,
            "bounds": {"x": (-1.15, 1.15), "y": (-1.15, 1.15), "z": (-1.15, 1.15)},
            "exact_vol": (4.0 / 3.0) * math.pi
        },
        "Ellipsoid": {
            "inside_fn": is_inside_ellipsoid,
            "bounds": {"x": (-1.15, 1.15), "y": (-0.8, 0.8), "z": (-0.6, 0.6)},
            "exact_vol": (4.0 / 3.0) * math.pi * 1.0 * 0.7 * 0.5
        },
        "Torus": {
            "inside_fn": is_inside_torus,
            "bounds": {"x": (-1.15, 1.15), "y": (-1.15, 1.15), "z": (-0.35, 0.35)},
            "exact_vol": 2.0 * (math.pi**2) * 0.7 * (0.3**2)
        },
        "3D Heart (Taubin)": {
            "inside_fn": is_inside_heart,
            "bounds": {"x": (-1.25, 1.25), "y": (-1.25, 1.25), "z": (-1.25, 1.55)},
            "exact_vol": 1.215560
        },
        "Custom Surface (z = sin x * sin y)": {
            "inside_fn": is_inside_custom_fn,
            "func": custom_function,
            "bounds": {"x": (0.0, math.pi), "y": (0.0, math.pi), "z": (0.0, 1.15)},
            "exact_vol": 4.0
        }
    }
    
    print("=" * 78)
    print(f" 3D VOLUME INTEGRATION STUDY (Monte Carlo N={mc_samples:,}, Simpson's n={simp_subdivisions})")
    print("=" * 78)
    row_fmt = "| {:<22} | {:<12} | {:<12} | {:<12} | {:<10} |"
    print(row_fmt.format("Shape / Function", "Exact Vol", "MC Est", "Simpson Est", "MC Error"))
    print("-" * 78)
    
    for name, info in shapes.items():
        bounds = info["bounds"]
        exact = info["exact_vol"]
        
        mc_est, mc_se, mc_ci = monte_carlo_3d(info["inside_fn"], bounds, mc_samples)
        mc_err = abs(mc_est - exact) / exact * 100.0 if exact else 0.0
        
        if "func" in info:
            simp_est = simpson_2d_double_integral(info["func"], {"x": bounds["x"], "y": bounds["y"]}, 100)
        else:
            simp_est = simpson_3d_grid(info["inside_fn"], bounds, simp_subdivisions)
            
        print(row_fmt.format(name[:22], f"{exact:.6f}", f"{mc_est:.6f}", f"{simp_est:.6f}", f"{mc_err:.4f}%"))
        
    print("=" * 78)

if __name__ == "__main__":
    main()
